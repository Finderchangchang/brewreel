# 风格蒸馏：把一支参考视频变成一个可复用的风格包

English: [README.en.md](README.en.md)

目标：看到一支好看的短视频，把它的**做法**（不是它的素材）拆成规格，做成组件，让便宜模型只填字段就能出同样完成度的片子。五步，每步有一份可复用的提示词，任何 AI 编程助手（Claude Code、Codex、Cursor……）都能照做。

| 步骤 | 产出 | 提示词 | 谁做 |
|---|---|---|---|
| 1. 拆解 | 九层拆解 + 逐拍表 + tokens 草稿（放仓库外） | `prompts/01-breakdown.md` | 强模型，配合 `scripts/extract-frames.mjs` 的实测数据 |
| 2. 老师示范复刻 | 用我们自己的素材手写一支「像它」的片子，确认哪些是关键 | `prompts/02-replicate.md` | 强模型 |
| 3. 组件化 | `template/src/styles/<id>/` 的令牌、镜头、规格；`styles/<id>/` 的文档和规则 | `prompts/03-componentize.md` | 强模型 |
| 4. 便宜模型测试 | 便宜模型只读文档写 3 份分镜并出片，记下它写错的地方 | 直接用 `SKILL.md` 流程 | 便宜模型 |
| 5. 评审修复 | 对照参考片打分，列问题，修规则和组件 | `prompts/04-review.md` | 另一个模型或人 |

## 第 1 步要的实测数据

```
node scripts/extract-frames.mjs <参考视频> --out <仓库外目录> --fps 4 --audio
```

得到 `info.json`（时长、分辨率、帧率、场景切换点、变化最大的时刻）、`frames/`（每秒 4 张）、`contact.html`（总览）、`cuts/`（每个切点后的第一帧）、`audio.wav`（找节拍、判断有没有旁白）。设 `FFMPEG` 环境变量指向完整版 ffmpeg 时还会出 `contact.jpg` 拼图。

## 版权口径（每一步都适用）

- 参考视频、截图、抽帧、角色、品牌名、网址、影视片段都**只在仓库外**。
- 仓库里只放我们自己写的拆解文字、自己画的角色和场景、自己编的示例内容；文档里写「参考了一支 X 类短视频」，不写对方品牌名。
- 拆解时把对方的品牌资产单独列成「必须避开」清单，并写明替代做法（换角色、换默认配色、换落版方式）。

## 完成标准

- 便宜模型只看 `SKILL.md` + `styles/<id>/STYLE.md` + `recipes.md` 就能写出能过校验的分镜；
- 出片第 0 帧有内容和钩子，字号守底线，关键内容在安全区；
- 和参考片放在一起看，完成度可比，但一眼能看出不是同一家的东西；
- 和仓库里已有的风格一眼能区分。
