# 提示词：再设计（换皮）

调配方流程第 3 步，在「复刻」之后、「组件化」之前。把下面整段交给 AI 编程助手，替换尖括号里的内容。

---

你负责把复刻稿的**皮肤**全部换成我们自己的，**骨架不动**。目标：同一类型，但熟悉参考片的人一眼看得出不是同一家；质量不能下降。

输入：
- `<仓库外路径>/breakdown.md`（拆解；附录有「对方品牌资产 / 必须避开」）
- `<仓库外路径>/signatures.md`（招牌清单，每条带编号；没有就先按下面的格式从拆解附录和逐拍表整理一份）
- `<仓库外路径>/tokens.json`（参考片实测色板）
- 上一步的「关键要素清单」、复刻代码 `template/src/styles/<id>/`
- 仓库里的 `distill/README.md`（「骨架层 vs 皮肤层」一节）、`styles/_template/originality.md`

招牌清单格式（放仓库外，编号定下来就不再改）：

```
## 参考招牌元素（必须避开）
- [S1] 标题旁固定形状、固定颜色的问号方块
- [S2] 角落里探头的小人
- [S3] 每条结尾都用的同一句互动口号
```

招牌 = 让人认出「这是那一家」的东西：品牌资产（名字、logo、网址、口号）、角色造型与人设配色、固定位置的小图形、固定出场方式、固定句式、固定的收尾组合、那组配色本身。拿不准就算招牌。

步骤：
1. **分层**：把拆解里的每个要素标成骨架或皮肤（判断方法：换掉之后观众还认不认得出是哪一家）。骨架照旧；皮肤进下面的清单。
2. **逐条换招牌**：清单里每一条给 2 个替换方案，写优缺点，选一个。替换不能只换颜色：形状、位置、出场方式、用途里至少换两样。选定后写进 `styles/<id>/originality.md` 的招牌表，一条一行：`| S2 | 角落探头的小人 | 已替换为：角色只在剧情镜头从底部滑入 |`；整条不要的写 `已删除（原因）`。
3. **配色**：先写一句自己的「色彩故事」（什么场景、什么情绪、和产品什么关系），再定 背景 / 主色 / 强调色 / 深色（描边），每个主题都定。
   - 硬线：有彩色离参考的每个有彩色 ΔE00 ≥ 20；背景离参考背景 ≥ 8；主色 + 强调色不能同时落在参考某两色的 25 以内；描边不能用参考那个近黑色。
   - 道具色、类别色、天色、角色配色也要自己定；写在代码里的（如 `art/` 下的配色文件）用 `--extra` 一起查，不能原样照搬参考色（< 3）。
   - `--suggest` 给的色只是「离原色最近又过线」的参考，按色彩故事重新搭，不要整盘采用。
   - 主题里的主色、强调色键名不是 primary / highlight 时，在 `tokens.json` 里加 `"$originality": {"primary": "<键名>", "accent": "<键名>"}`，否则组合检查会跳过。
4. **字体处理**：字重对比、描边 / 投影方式、强调手法（马克笔底、删除线、下划线、底块）至少换掉参考片最显眼的那一种。字号底线不变（正文 40 / 面板 34 / 最小 26）。
5. **角色**：造型、剪影、人设配色、服装、标志物、变身细节全部自己设计。和参考角色并排放，剪影、配色、标志物三样里不能有任何一样相同；不描摹、不「换个颜色」。
6. **固定句式**：参考片每条都用的提问句、复听句、互动句、口号，每一类写 2–3 个我们自己的句式，写进 `recipes.md` 让模型轮换；spec 的 example 和规则里不许出现参考片原句。
7. **收尾方式**：落版版式、品牌出场动画、数据展示方式换成自己的（骨架「结尾回到产品」可以留）。
8. **写记录**：填完 `styles/<id>/originality.md`（保留了哪些骨架、每类皮肤换成了什么、检查结果）。文档里不写参考品牌名，一律抽象描述。
9. **检查与自测**：
   ```
   node scripts/check-originality.mjs --style <id> --ref <仓库外路径>/tokens.json --signatures <仓库外路径>/signatures.md [--extra <配色文件>] --svg <仓库外路径>/originality.svg
   ```
   不过就改到过；过了再用 ShotLab 出关键帧、`make.mjs --out <仓库外目录>` 出整片，和参考片同一秒的关键帧并排放，按 `04-review.md` 第 5 项先给自己打一次混淆度。守住底线：第 0 帧有内容和钩子、字号、安全区、每镜会动的主角。

交付（纯文本）：
- 替换对照表：招牌逐条（编号 / 参考做法的抽象描述 / 我们的做法）+ 配色新旧对照（键名 / 旧色 / 新色 / 离参考最近 ΔE00）；
- `check-originality` 的输出和色块图路径；
- 并排关键帧对比图路径（仓库外）；
- 自评混淆度（1–10）和最像参考片的三处；
- 改动的文件清单。
