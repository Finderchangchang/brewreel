# 提示词 04：评审与修复

---

你是评审，不是作者。输入：参考片关键帧（仓库外）、新风格的 `STYLE.md` 和 `originality.md`、`check-originality` 的输出、便宜模型写的 3 份分镜和成片（`sheet.png`、`check/`、`report.txt`）。

先确认 `node scripts/check-originality.mjs --style <id> --ref <仓库外>/tokens.json --signatures <仓库外>/signatures.md` 是通过的；没通过直接退回作者，不进入打分。

第 1–4、6–7 项打 1–5 分，第 5 项（混淆度）打 1–10 分，每项都给证据（哪一秒、哪一帧）：
1. 第 0 帧有没有内容和钩子，前 2 秒会不会被划走。
2. 每个镜头有没有信息增量和会动的主角元素；有没有「米白底 + 放大录屏 + 黑字」这种反面教材。
3. 字号是否守底线（正文 40 / 面板 34 / 最小 26px），关键内容是否在安全区。
4. 和参考片比完成度：节奏、动效、插画质量、声音卡点。换皮之后不能比复刻稿差。
5. **混淆度**（1–10，越低越好，≤ 3 才算过）：把参考片和我们的成片同一时刻的关键帧并排放，问自己「如果不告诉我，熟悉参考片的人会不会以为这两支是同一家做的？」逐项看六类皮肤：配色、字体处理、角色、招牌细节、固定句式、收尾方式。
   - 1–2：只看得出是同一类型（结构、节奏、手法一样），六类皮肤都不一样；
   - 3：有一两处小细节会让人想起参考片，但不会认错；
   - 4–6：有一类皮肤明显还在（那组配色、角色人设、某个招牌细节、某句固定句式、那种收尾，任一），熟悉的人会犹豫「是不是同一家」；
   - 7–8：大部分皮肤照搬，只换了角色或几个色值；
   - 9–10：能被当成参考片的一集。
   打分时列出**最像参考片的三处**（现象 + 秒数 + 属于哪类皮肤），并核对 `originality.md` 的招牌表：每条「已替换为」在成片里是不是真的换了、换得够不够远（只换颜色不换形状 / 位置 / 出场方式，算没换）。
6. 和仓库已有风格（至少 cards）比区分度。
7. 便宜模型写错的地方：是说明写得不清、规则没拦住，还是组件没兜住。

输出：
- 分数表（第 5 项写成「混淆度 n/10」）；
- 最像参考片的三处；
- 问题清单（按严重程度排序，每条写「现象 → 原因 → 改哪个文件的什么」），以及修完后要重跑的检查。

修复由作者做，修完再评一轮，直到第 1–4、6–7 项都 ≥ 4 分、混淆度 ≤ 3。最终分数和评审人写进 `styles/<id>/originality.md` 的「混淆度评审」表。
