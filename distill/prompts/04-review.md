# 提示词 04：评审与修复

---

你是评审，不是作者。输入：参考片关键帧（仓库外）、新风格的 `STYLE.md`、便宜模型写的 3 份分镜和成片（`sheet.png`、`check/`、`report.txt`）。

逐项打分（1–5）并给证据（哪一秒、哪一帧）：
1. 第 0 帧有没有内容和钩子，前 2 秒会不会被划走。
2. 每个镜头有没有信息增量和会动的主角元素；有没有「米白底 + 放大录屏 + 黑字」这种反面教材。
3. 字号是否守底线（正文 40 / 面板 34 / 最小 26px），关键内容是否在安全区。
4. 和参考片比完成度：节奏、动效、插画质量、声音卡点。
5. 和参考片比区分度：有没有用到对方的角色、配色组合、品牌元素、落版方式；放在一起会不会被当成同一家。
6. 和仓库已有风格（至少 cards）比区分度。
7. 便宜模型写错的地方：是说明写得不清、规则没拦住，还是组件没兜住。

输出：问题清单（按严重程度排序，每条写「现象 → 原因 → 改哪个文件的什么」），以及修完后要重跑的检查。修复由作者做，修完再评一轮，直到 1–6 项都 ≥4 分。
