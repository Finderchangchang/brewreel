# cutpaper-collage 原创性记录

参考的是一支竖版户外出行剪纸短片。招牌原件在仓库外。这里只写我们换成了什么。

## 1. 保留的骨架

| 骨架 | 我们怎么用 |
|---|---|
| 全片一块锚点物件 | 一张手剪票券，开场、补丁、翻滚、收尾都是它 |
| 换场靠形状和颜色接力 | 缩成补丁、收到圆窗，倾斜和锚点色接上，不用淡化 |
| 一底色、一支锚点色、一个深色 | 底色按镜头换，洋红只跟票券和窗里的旋转走 |
| 全片一层纸纹 | 纸纹盖在平涂上，票券边缘不模糊 |
| 一次上抛再落下 | 开场票券上抛，角度过冲一次，然后停 |
| 碎屑只在纸底镜头 | 开场和收尾有碎屑，插画镜头关掉，交接前退场 |
| 锚点离开时用小角色带路 | 纸蛾只出现一次，再落到票券边上 |
| 镜头大约两秒一换 | 时长不锁拍。超过三秒半的镜头里票券自己在动 |

## 2. 招牌

| 编号 | 抽象描述 | 处理 |
|---|---|---|
| S1 | 参考片那一对纸底和锚点色，以及极近的邻色 | 已替换为：浅紫纸底加洋红票券。底可以换，洋红不换 |
| S2 | 只在纸底镜头里飞的三块高饱和碎屑 | 已替换为：赭石、暗绿、深褐。不跟锚点色抢 |
| S3 | 按固定顺序轮换的一整套底色 | 已替换为：浅紫、粉墙、草地、奶油、浅洋红对调、灰紫木盆。顺序和色相都换过 |
| S4 | 全片纸纹，加上锚点右下方的那支投影色 | 已替换为：同一层纸纹。投影是当前底色压暗，方向仍偏下 |
| S5 | 一个固定不规则多边形和它的静止角度 | 已替换为：种子稳定的手剪票券，静止倾斜 +6 度 |
| S6 | 眉题加一行固定句式的开场字 | 已替换为：第 0 帧只有一句中文标题，没有拉丁眉题 |
| S7 | 收尾字标的字母、横线和下面的图形 | 已替换为：票券上写「回针」，下面一根针的折线，没有字母标志 |
| S8 | 同一枚标志印在每件道具和风景角上 | 已删除（标志只在收尾票券上出现一次） |
| S9 | 带路的小虫子和它的配色 | 已替换为：一只纸蛾，只飞一次，落到票券外缘 |
| S10 | 衣架上的衣服特写和腿上的那块补丁 | 已替换为：三件旧衣剪影，补丁在左侧衣身，尺度约 0.22 |
| S11 | 圆角风景卡里的山和树 | 已替换为：近山、土路、太阳。没有雪，没有树的具体品种 |
| S12 | 圆窗后面的那台机器 | 已替换为：一只圆口木盆，窗里两色旋转 |
| S13 | 草丛的具体画法和叶子上的虫子 | 已替换为：平涂草叶、土路、太阳。虫子不进草丛 |
| S14 | 开场先给空白卡，字和碎屑晚一拍 | 已替换为：第 0 帧票券上已经有标题 |
| S15 | 从一侧擦入、缩到补丁上的那一次接力 | 已替换为：从左侧擦入，落到左侧衣身，倾斜保持 +6 度 |
| S16 | 收尾从补丁硬切回整卡 | 已替换为：四帧左右切回同一中心，再落下一小段，然后停 |

## 3. 配色

纸底浅紫，锚点洋红，字在票券上用暖白，在浅底上用墨。深色做衣边和投影。碎屑用赭石、暗绿、深褐。正文字体用仓库里的 Noto Sans SC。
