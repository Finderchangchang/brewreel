# techbrief 原创性记录

参考的是一支竖版 AI 资讯口播。招牌原件在仓库外。这里只写我们换成了什么。

## 1. 保留的骨架

| 骨架 | 我们怎么用 |
|---|---|
| 一块舞台换内容，背景不跟着切 | 暖褐底加平网格，卡片在上面换 |
| 证据放进一块卡片，结论和证据分开 | hero 主卡是结论，辅条是补充；stack 是并列要点 |
| 一个强调色只标这一屏的重点 | 森林绿短条，不铺满句子 |
| 入场短、停得住，不回弹 | 性格 push，0.30 秒、64 像素向上推入 |
| 节奏跟口播，不锁拍 | 仍用现有的按字数估时长 |

## 2. 招牌

| 编号 | 抽象描述 | 处理 |
|---|---|---|
| S1 | 高饱和黄绿强调 | 已替换为：强调色用森林绿，只做卡片上的短标 |
| S2 | 近黑舞台、四角暗角、片尾换成另一块浅底 | 已替换为：全程一块暖褐舞台，不切到浅底落版 |
| S3 | 向上汇聚的透视网格 | 已替换为：间距 80 像素的平面方格 |
| S4 | 大圆角白截图卡，贴边很宽 | 已替换为：圆角 8，卡片停在安全区里 |
| S5 | 左上角圆点加极小的栏目标 | 已替换为：栏目标用仓库已有的 Cascadia Mono，字号停在辅文下限，不小于最小字号 |
| S6 | 网格上的超大裸数字 | 已替换为：数字直接压在舞台上，不进卡片；字号封在标题上限，并且至少是同屏说明的两倍。不照搬参考片的 253 像素，也不用那套黄绿 |
| S7 | 安全区以下的居中口播字幕 | 已替换为：补充句放在主卡下面，仍在安全区内 |
| S8 | 句子中间把词涂成强调色 | 已替换为：强调用短色条，不改字的颜色 |
| S9 | 大字入场带模糊，并留下上一屏残影 | 已替换为：清晰的向上推入，没有模糊，也没有残影 |
| S10 | 片尾圆头像和名字 | 已删除（落版只用品牌名和一句收束） |
| S11 | 截图素材自带的橙色顶条 | 已删除（不搬素材界面的颜色） |
| S12 | 代码画面里的语法蓝 | 已删除（不把素材色收进令牌） |

## 3. 配色

舞台暖褐，证据卡是米纸，字是墨色，强调是森林绿。正文字体用仓库里的 Noto Sans SC。栏目标和舞台数字用 Cascadia Mono（注册名 PMono）。
