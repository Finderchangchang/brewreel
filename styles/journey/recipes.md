# journey 风格的叙事模板

便宜模型只写分镜 JSON：`meta` + `shots`（`opening` → `district` × 4–6 → `finale`）。画面、镜头运动、天色、音效、笑点时刻都由风格自动算，**不用写时长以外的任何画面参数**。先抄一份 `examples/` 里最像的样例再改字。

**字段一律写在 `params` 里**，镜头顶层只有 `type`、`dur`、`params`：

```json
{"type": "district", "dur": 4, "params": {"category": "预算提醒", "title": "月底前三天，提醒你收手", "scene": "phone"}}
```

`meta.theme` 不用写（这个风格不用 cards 的配色）；`cta` 这类可选字段没有就整个删掉，不要写空字符串。

## 通用字段（每套模板都一样）

**meta**

| 字段 | 必填 | 写什么 |
|---|---|---|
| `style` | 是 | `"journey"` |
| `aspect` | 否 | `"4:5"`（默认）或 `"9:16"` |
| `product` | 是 | 产品名，片尾品牌卡、左上品牌胶囊、浏览器地址栏都用它 |
| `action` | 是 | 用户用它做的一件事（「打开 → 做什么 → 得到什么」），不上屏，给校验看 |
| `cta` | 否 | 简报「获取方式」原句；没有就不写 |
| `facts` | 有数字就必填 | 简报里的数字、价格、时间原句，`{id, text, source}`；片尾 stats、钩子里的总量、任何「N 元 / HH:MM / N 小时」都只能从这里抄 |
| `industry` | 否 | software（默认）/ food / ecommerce / education / beauty / travel |
| `disclaimer` + `demoData` | 示例数据时必填 | 如「演示画面，数据为示例」+ `true` |

**每拍字段与字数**

| 段 | 镜头 | 拍 | 字段（字数上限） | 自动 |
|---|---|---|---|---|
| 钩子 | `opening` | 0–3（2 秒） | `headline` 数字 + 单位 ≤6（数字 = 街区数，或在 facts 里；句式见下）；`kicker` ≤10；`go` 口令 ≤5（可选）；`skyline` 背景 `modern` / `street` / `oldtown`（可选，默认 modern） | 第 0 帧完整城市 + 角色 + 大字；第 1 拍口令气泡；后半段起飞 |
| 街区 | `district` | 0 | `category` 类别名 2–6 字（4 字最好，全片不重复，**写完整的词，别截成半个**：「预算提醒」不能写「预算提」） | 路牌经过、类别胶囊切换、进度点 +1 |
| | | 0.3–7.2 | `title` 代表内容 ≤20（两行，每行约 12 字；超过 10 字在意群之间加逗号）；`tag` ≤6、`source` ≤14（都可选） | 广告牌边升起边弹出，一直停到第 7.2 拍 |
| | | 3–6 | `scene` 14 选 1（相邻不同，要配得上 skyline，见下表）；`burst` 拟声 ≤5、`bubble` 台词 ≤10（都可选，不写用默认） | 道具到角色面前、减速、换表情、音效 |
| | | 6–8 | — | 恢复巡航；第 7.2 拍广告牌收起，下一站的牌子紧接着升起 |
| 片尾 | `finale` | 0–2.6 | `stats` 1–2 个 `{value ≤6, unit ≤5}`（value 必须在 facts 里）；`sub` ≤14 | 减速停下、数字卡落下计数 |
| | | 2.6–结尾 | `slogan` ≤12（必填）；`brand`（可不写 = product）；`cta`（= meta.cta）；`bye` ≤8 | 缩进浏览器框、品牌卡、类别 chips、数据胶囊、彩纸、角色出框挥手 |

片尾至少要有一个数字（`stats`）或获取方式（`cta`），不然落版只剩一句口号（J16 提醒）；虚构产品没有真实数据时，可以用 facts 里的计数，如「6 个功能」（先把「共 6 个功能」写进 meta.facts）。

时长：`opening` 2 秒（1.5–3），`district` 4 秒（3.5–5，写整拍），`finale` 4–6 秒（默认 5；和参考节奏对齐用 4）。总时长 16–40 秒。

**钩子句式**（按题材套，J14 会提醒照搬出来的怪词）：内容站「N 篇精选」「N 个栏目」；软件「N 个功能」；文旅「N 站慢游」；门店「N 家店」。不要写「N 个账本街」「产品名 + 街」这种观众看不懂的词，产品名也不用写进大字（左上胶囊和片尾都有）。

**背景天际线 `skyline`**（写在 opening.params，整片一个）：`modern` 现代城市（软件、内容平台，默认）/ `street` 低层街巷（小店、社区、生活服务、播客电台这类「街坊感」）/ `oldtown` 古城（古镇、老街、古城游、水乡）。**古城古镇题材必须写 oldtown**（J12 拦）。

**scene 怎么选**（道具要和这一站的内容对得上；J11 拦和背景配不上的）：

| scene | 画面 | 配什么内容 | 能用的背景 |
|---|---|---|---|
| `stack` | 文件柜楼、活页夹楼，跳过书塔 | 文档、长文、资料、收藏 | modern / street |
| `launch` | 发射塔、火箭倒数升空 | 新品、上线、发布 | modern / street |
| `factory` | 工具箱楼、塔吊、机械臂掸灰 | 自动化、整理、修复 | modern / street |
| `studio` | 铅笔塔、颜料桶楼、相机闪光 | 图片、设计、拍照、视觉 | modern / street |
| `observatory` | 柱状图楼、饼图穹顶、机器鸟 | 数据、报表、研究、灵感 | modern / street |
| `neon` | 夜景霓虹街（屋顶牌写本站类别名） | 夜间、搜索、深夜节目（只放最后一站） | modern / street |
| `phone` | 手机形大楼、小票店，扫一下打勾 | App 操作、拍照记录、扫码、提醒 | modern / street |
| `home` | 公寓亮灯、爱心飘来 | 家庭、共享、社区、住 | modern / street |
| `cafe` | 屋顶大咖啡杯、递来一杯咖啡 | 饮品、早餐、休闲、办公 | modern / street |
| `market` | 条纹布篷摊位、接住礼盒 | 吃的、买的、逛摊、早市 | 三种都行 |
| `gate` | 城墙城楼、相机打卡 | 城门、古建、拍照点 | oldtown |
| `bridge` | 三孔石桥、河、乌篷船、燕子 | 桥、河、水乡、游船 | oldtown |
| `teahouse` | 木楼茶馆、蓝染布、递来一杯茶 | 茶馆、老铺、手作体验 | oldtown / street |
| `lantern` | 牌楼、红灯笼一路亮起 | 灯会、夜市、夜游（只放最后一站） | oldtown / street |

## 模板一：栏目巡游（内容平台 / 资讯站 / 课程体系）

一站一个栏目，广告牌写这个栏目里的一条代表内容，结尾给收录总量。

- 钩子：`kicker`「跟橘团一口气飞过」+ `headline`「600篇精选」（600 必须在 facts 里）或「6 个栏目」。
- 街区 5–6 个，按每个栏目的内容挑 scene（上表），相邻不同；有夜间 / 深夜栏目就放最后配 `neon`。背景可选 `street`（电台、播客的街坊感）；`title` 写成一条真实感的标题，不写「最 / 第一 / 全网」。
- 片尾：`stats` 用「收录篇数 + 栏目数」，`slogan` 一句读者得到什么。
- 样例：`examples/content-podcast.json`（4:5，5 站，街巷背景）；老师示范用的也是这套（6 站 30 秒）。

## 模板二：功能巡游（软件产品）

一站一个功能，广告牌写这个功能最常见的一件事（场景句，不写参数表）。

- 钩子：`headline`「6 个功能」这类「街区数 + 单位」，不用编总量。
- 街区 4–6 个：App 里的操作（拍小票、扫码、提醒）配 `phone`，家庭 / 共享配 `home`，发布类功能配 `launch`，自动化配 `factory`，识图 / 拍照配 `studio`，灵感 / 报表配 `observatory`，搜索放最后配 `neon`。记账、待办这类工具，街区大多该落在 `phone` / `home` / `observatory` 上，别用发射塔、颜料桶去配记账功能。
- 片尾：`stats` 只用简报给的数（模板数、格式数），没给就不写 `stats`。
- 样例：`examples/software-notes.json`（9:16，6 站）。

## 模板三：游线（文旅 / 多门店 / 一条街）

一站一个景点或体验，按实际游览顺序排；价格、开放时间、时长写在 `title` 或 `source` 里，**一律抄简报原句进 meta.facts**（J8 会逐个核对）。

- 钩子：`headline`「5 站慢游」（= 街区数）。古城、古镇、老街题材在 opening.params 写 `"skyline": "oldtown"`。
- 街区 4–5 个（古城）：早市 / 小吃配 `market`，城门 / 古建配 `gate`，桥 / 河 / 游船配 `bridge`，茶馆 / 老铺 / 手作体验配 `teahouse`，夜游灯会放最后配 `lantern`。现代景区用默认背景，按上表挑。
- `meta.industry` 写 `travel`：不写「绝美 / 宝藏 / 几分钟就到 / 一日游」这类词；季节景观写月份；高风险项目要加限制提示。
- 片尾：`stats` 写「5 站游线」这类简报里有的数；有获取方式就写 `meta.cta`。
- 样例：`examples/travel-town.json`（9:16，5 站，古城背景）。

## 常见被拦 / 被提醒的写法

- 促销字眼（限时、特价、今日特价…）会要求写活动起止日期。**不是真实活动就删掉那个词**；别为了过校验在 notices 里编一条「限时体验：X月X日至X月X日」——日期必须在 meta.facts 里有简报原句，编了照样被拦。
- 类别名截断（「拍照记」「预算提」）、钩子照搬（「5 个账本街」）、长标题不加逗号，都会被提醒；按提示改完再出片。
