> 调配方流程第 3 步「再设计」的交付物（方法见 `distill/README.md`）。

## 1. 保留的骨架（类型层，可以沿用）

| 骨架 | 我们怎么用 |
|---|---|
| 叙事结构 | 钩子（4 拍）→ 街区 × 4–6（每个 8 拍：路牌 → 代表内容 → 笑点 → 恢复巡航）→ 收尾（8–10 拍） |
| 节奏 | 120 BPM，每街区 8 拍；整拍给路牌和换站，拟声音效落在拍后 |
| 动效手法 | 气泡从尾巴弹出、拟声字旋转过冲、表情硬切 + 压扁；减速当特写 |
| 镜头语言 | 一镜到底横向平移，角色屏幕锁定在左 35%，三层视差（远 0.12 / 中 0.55 / 近 1.0），笑点窗口减速到 0.52–0.7 倍 |
| 版式原则 | 上三分之一放信息、中间是角色和笑点、下四分之一是街面；视线 = 运动方向，道具从右边来 |
| 时间推进 | 天色白天 → 午后 → 黄昏 → 夜，最后一站是夜 |

## 2. 重做的皮肤（我们自己的）

整套皮肤的主题是「旅行文具」：车票（信息层）→ 明信片（每站的内容）→ 同一张车票检票、翻面（收尾），开场是车站翻牌。

### 2.2 字体处理

- 开场大字：参考是品牌红填充 + 粗描边 + 硬投影的大数字。我们是**翻牌站牌**：每个字一块深色翻牌（中缝 + 两侧轴钉），字是纸白、数字是青柠，牌子依次「翻一下」，退场时逐块上翻。
- 小引：参考是常规字重的一行小字。我们是粗字 + 荧光笔底色。
- 强调：获取方式同样用荧光笔底色；片尾最多一个数字，挂在车票正面终点旗旁当这趟路线的累计（出票机打印，不滚动计数、不做胶囊），车票背面不放数字；不用描边字。

### 2.3 角色

角色和载具由美术负责（`template/src/styles/journey/art/`，见 `art/README.md`）：原创吉祥物「橘团」（小熊猫，翡翠绿围巾）踩钴蓝悬浮滑板（板面一道金黄条、金黄尾旗），不用参考片的纸页拟人 + 纸飞机组合。

整座城换成「剪纸分层」造型语言：远景、中景、近景和角色各是一张纸，每层身后投一道往右下错开的硬边纸影（越近越深）；天空是五张上沿带波浪的色纸叠起来，太阳是三层纸圆片、月亮是剪出来的月牙；楼身两角剪圆、平顶改圆头压条、门改拱门；窗是墙上剪出的洞（不描边，上沿和左沿露一道纸厚的影子）。参考片是平涂 + 统一近黑描边 + 平滑天空渐变。描边读默认主题的 `ink`（石墨 `#23262E`），不再用参考的暖近黑。

### 2.5 固定文案句式

只改拟声字不够：桥段本身就是招牌（S12），所以 v0.2.1 连桥段带台词一起换。

| 参考片的句式 / 桥段（抽象） | v0.2.0 的写法 | v0.2.1 的写法 |
|---|---|---|
| 小引「跟{角色}一口气飞越 …」 | 「跟橘团一口气逛完」 | 写路线或看点：「这趟车停 5 站」「从早市走到灯会」「通勤路上换五个台」；套「跟 X 一口气…」由 J18 提醒 |

### 2.6 收尾方式

参考：数字卡从顶部落下滚动计数 → 整个画面 0.3 秒缩进浏览器框（地址栏）→ 中央品牌卡 + chips + 数据胶囊 + 彩纸，角色出框。

v0.2.1（已删除）：城市压暗 → 集章卡升起 → 逐站盖类别色站章 → 数据计数 →「到站」圆章 + 口号 + 获取方式 → 打孔纸屑；角色在卡片右下角欢呼说「下一班见」。复评指出这套元件和参考落版一一对应（品牌卡 ↔ 集章卡卡头、类别 chips ↔ 类别色站章、数据胶囊 ↔ 数据栏、彩纸 ↔ 打孔纸屑、出框挥手 ↔ 角落欢呼 + 告别），只是换了外衣；另外集章卡从画面外升起，压暗后约 1 秒画面上什么都没有。

我们（v0.3.0，终点检票）：相机停在终点，城市转成夜景暖光（不缩框、不换画面、不放产品界面；四周 multiply 压成石油蓝但楼和窗灯保留原色，车票身后一圈 screen 暖光，车票最亮）→ 顶部车票同一时刻滑到画面中间、往下展开成大票（正面：全程已走完 + 路线 + 站号；转夜景和车票移动同时开始，没有空帧）→ 角色一跳站到票的上沿 → 有数字时，出票机在终点旗上方打出一行累计 → 检票钳在票根上打孔、掉一粒纸屑 → 车票翻面（侧对镜头时露出纸边，不出空帧）→ 背面：终点站 + 产品名、口号、获取方式 → 角色蹲一下、踩滑板冲出画面右侧 → 最后约 2 秒只有这张车票。信息结构是「一张票的正反面」：正面回顾路线（数字是路线的累计），背面只给产品和一句话。收尾没有新元件入场，没有类别色块、并排数字、彩纸和告别；角色不守在落版旁。
