# journey 风格（角色漫游）

> 状态：**stable**。从一类「角色漫游」短视频里学的是**骨架**（一镜到底横移、多层视差、一站一个类别、每站一个小笑点、时间推进、减速当特写）；**皮肤全部是本项目自己的**：「旅行文具」一套——顶部一张车票、每站一张明信片、开场翻牌站牌、片尾集章卡盖章，配色是邮路绿 / 石墨 / 荧光青柠。参考视频、截图、角色、品牌、网址都不进仓库。和参考片逐项怎么区分、配色怎么量，见 [`originality.md`](originality.md)。

一个吉祥物（角色设定见 `template/src/styles/journey/art/README.md`）乘悬浮滑板，从左到右一镜到底横穿一座扁平插画城市。顶部一张车票标着整条路线：每到一站，车票上的当前站切到这一站，一张航空信封边的明信片从右边甩进来，写这一类的代表内容，看完就「寄出」、缩进车票上这一站的站点。天色从白天走到夜晚，到终点后城市压暗，一张集章卡升起，每一站依次盖章，最后盖一枚「到站」大章。

## 1. 基本参数

- 默认 4:5（1080×1350），也支持 9:16；30 fps；120 BPM（一拍 0.5 秒）。
- 一镜到底，没有切点，片尾也不缩框、不换画面（城市停在终点、压暗）。
- 每个街区 8 拍（4 秒），车票的当前站在每个街区的第 0 拍准点切换。
- 没有旁白，台词全靠气泡和拟声字。
- 典型长度：钩子 2 秒 + 6 个街区 24 秒 + 片尾 5 秒 = 31 秒；4 个街区约 23 秒。

## 2. 叙事结构

`opening`（4 拍）→ `district` × 4–6（每个 8 拍）→ `finale`（8–10 拍：减速停在终点、集章卡升起、逐站盖章、数据计数、「到站」大章 + 口号）。

每个街区的 8 拍（由 `district` 的 `scene` 决定地标、道具和笑点，时刻写在 `tokens.json` 的 `scenes`）：

| 拍 | 发生什么 |
|---|---|
| 0 | 类别色箭头路牌经过角色（下挂「第几站」小牌）；车票上的当前站切到这一站（站号 + 站名），路线上的小圆钉开始往下一站走 |
| 0.3 | 明信片从右边画外甩进来（带一点旋转，弹簧落位），0.1 秒后出字：类别名 + 标签、标题、出处，邮票上是站号 |
| 0.3–7.1 | 明信片停在画面上三分之一处轻轻浮动，标题一直完整可读（文字框在安全区里，9:16 是 x180–900） |
| 3–6 | 本街区的笑点：道具正好到角色面前，镜头减速到 0.52–0.7 倍，角色换姿态和表情，拟声字 + 音效，随后气泡台词 |
| 3.2 | 自查检查帧抽在这一拍（spec 的 `checkBeat`）：明信片标题和类别名必须看得见（`mustShow`） |
| 7.1 | 明信片「寄出」：缩小、转一下，飞进车票上这一站的站点（这一站的站点变成实心类别色） |
| 6–7 | 恢复巡航，下一块路牌入画 |

**背景天际线**（`opening.params.skyline`，整片一个）：`modern` 现代城市（默认）/ `street` 低层街巷（中景楼压到 2–4 层）/ `oldtown` 古城（远山 + 宝塔、白墙黛瓦马头墙、垂柳、石板路，9:16 路面下方是河）。古城、古镇、老街题材必须用 `oldtown`（J12）。

## 3. 视觉系统（本风格自己的皮肤）

- **配色**：UI 和落版用「邮路绿」主题 `post-green`——石墨描边 `#23262E`、邮政绿 `#1B6B2F`（车票票根、集章卡卡头、「到站」章、走过的路线）、荧光青柠 `#7CFC3A`（路线上的小圆钉、翻牌数字、荧光笔底色）、浅湖青纸色底 `#C6E1E7`（片尾压暗的纱）。二创示范主题 `plum-ticket`：酒红票根 `#7A1030` + 苔绿 `#4B760A` + 冷灰纸底。所有主题的有彩色都和参考片色板拉开 CIEDE2000 ≥ 20（数值见 `originality.md`）。
- **城市**（`template/src/styles/journey/art/`）：天空 → 远景天际线 → 中景淡色塔楼 + 主题剪影 → 近景主题街区 → 街面。每个街区一套主色，路牌、明信片的邮票和航空条纹、车票上走过的站点、片尾站章都用这个颜色；道具配色（`scenes.*.props`）写成槽位 `main / deep / mid / accent / white / ink`，自动取这个街区的美术配色，楼和道具一个色系。
- **天色**：一个进度值管全部（白天 → 午后 → 黄昏 → 蓝调 → 夜）。最后一个街区是夜，倒数第二个黄昏，倒数第三个暖色（≥5 个街区时），其余白天；两站之间约 2.2 秒过渡；窗灯、路灯、霓虹跟着亮。
- **车票（信息层）**：画面顶部一整条车票（4:5 在 y 112，9:16 在 y 272），左边是路线：起点圆点 → 各站站点 → 终点小旗，走过的一段是邮政绿实线、没走的是虚线，一颗青柠色小圆钉沿路线连续移动；当前站的上方写「站号 + 站名」；右边一截是邮政绿票根，写产品名，中间一条打孔虚线、上下各咬一个半圆缺口。
- **明信片（每站的信息载体）**：航空信封式斜条纹外框（本站类别色 + 主色 + 白），里面是纸；左上类别名 + 描边小标签，中间标题（≤2 行），底部一道短横线 + 出处；右上角贴一张齿孔邮票（类别色，印站号，压一枚虚线邮戳和两道波浪线）。每站轻微左右交替倾斜。夜里纸色偏暖，没有霓虹 / 故障模式。
- **开场大字**：翻牌站牌——大字每个字一块深色翻牌（中缝 + 两侧轴钉），数字用高亮色；小引是一行带荧光笔底色的粗字。
- **片尾**：集章卡——邮政绿卡头写产品名，下面是站章格（每站一枚类别色双线圆角印章，左上角编号），一道虚线下是数据栏：左边一枚「集章 k/n」小圆牌（跟着盖章数走），右边 1–2 个数据竖排成票面上的两行、出处小字在下（不用「数字 │ 数字」横排）；口号 + 带荧光笔底色的获取方式；右上角压一枚「到站」圆章；打孔纸屑（小圆点）落下。角色落在卡片右下角外侧，转身朝卡片欢呼，气泡说「下一班见」。
- **剪纸分层**：远景、中景、近景和角色各是一张纸，每层身后投一道往右下错开的硬边纸影（越近越深，夜里减弱）；天空是五张上沿带波浪的色纸叠起来，太阳是三层纸圆片、月亮是剪出的月牙；楼身两角剪圆、门是拱门，窗是墙上剪出的洞（不描边，上沿和左沿露一道纸厚的影子）。描边是石墨色：角色和近景 4–5px，中景不描边（低饱和 + 无描边 = 天然退后）。UI 元件的阴影是描边色的硬投影（右下偏移）。
- **字号**（1080 宽，都不低于底线）：翻牌大字 116（最小 64）、小引 48、车票站名 34 / 站号 26 / 票根产品名 30、明信片标题 46（最小 40，两行）、类别名 32、标签 / 出处 26、邮票站号 34、路牌 44 / 小牌 30、气泡 40、拟声 46、集章卡产品名 40、站章 30 / 编号 26、「到站」章 40、数据 64 / 36 / 28、口号 48、获取方式 40。
- **角色**：原创吉祥物踩悬浮滑板（造型、配色、表情见 `art/README.md`）。剧情表情 11 种全部硬切（常态 / 开心 / 兴奋 / 惊讶 / 压扁 / 松口气 / 后仰下腰 / 递出车票 / 好奇 / 摆拍 / 挥手），由 `parts/rider.tsx` 翻译成美术的姿态、表情和头顶特效。
- 配色主题（`themes`）只管 UI 和落版；城市和角色的颜色改 `tokens.json` 的 `art` 键（见 `art/README.md`）。

## 4. 镜头语言

- 角色屏幕锁定在画面左侧 35%，上下漂浮 ±16px（2 秒一周期）、左右微晃 ±8px（4 秒）；视线 = 运动方向，道具都从右边来。
- 视差：远景 0.12、中景 0.55（`camera.parallax.artFar/artMid`）、近景 1.0。明信片和车票是屏幕层（不跟世界滚），所以标题从出字到寄出一直停在同一个位置，读的时间有整整 6.8 拍。
- 相机 x(t) = ∫速度：开场怠速 65 px/s，钩子后半段起飞加速到巡航；每个街区的笑点窗口减速（`scenes.*.slow`）；片尾 1.3 秒减速到 0。**减速就是这个风格的特写。**
- 每个街区单独定巡航速度，让美术街区（2200 世界单位 × 城市缩放）正好首尾相接：4:5 缩放 0.9（一站约 1980px，巡航约 550 px/s），9:16 缩放 1.0（一站 2200px，约 610 px/s）。缩放写在 `tokens.layout.*.cityScale`。
- 世界坐标反推（`parts/plan.ts`）：路牌 = 第 0 拍到角色；道具 = 第 `gagAt` 拍到角色面前；整座城市再整体错开一点，让邮局街的邮筒楼正好在笑点拍停在角色前方（贴纸从它的投信口吐出来）。音画对齐不靠碰运气。
- 片尾没有景别变化：城市停在终点、压暗，集章卡从画面下方升起，角色一跳落到卡片右下角、转身朝卡片。

| `shots/*.spec.json` | 三个镜头的参数、字数、时长、音效卡点 |

## 7. 声音

- 整拍留给路牌（tick）和车票换站；拟声字都配一个音效，落在拍后（`scenes.*.sfx`，单位拍）；气泡不配音效。
- 开场：翻牌两声轻 tick、起飞 whoosh。片尾：集章卡升起 swish、盖章 tap ×4、数据 tick ×2 + 落定 ding、「到站」章 pop。
- 配乐按 120 BPM 生成；笑点音效落在拍后的反拍上。

## 8. 可变与不变

- 固定：描边、车票 / 明信片 / 邮票 / 集章卡的外形、视差比例、速度曲线、每街区 8 拍、天色走向、收尾方式。
- 便宜模型填：钩子数字和小引；每个街区的类别名、标题、街区类型（可选标签、出处、台词、拟声字）；片尾口号、获取方式、1–2 个数据。字段清单和字数见 `recipes.md`。
- 最少 13 个字符串出一支约 23 秒的片：钩子 1 个 + 4 ×（类别名 + 标题 + 街区类型）+ 口号（产品名默认取 `meta.product`）。

## 9. 规则（都已写成校验）

- spec：钩子大字 ≤6 字；小引 ≤10；类别名 ≤6；标题 ≤20；标签 ≤6；出处 ≤14；气泡 ≤10；拟声 ≤5；口号 ≤12；数据值 ≤6、单位 ≤5；时长范围和默认值。
- `rules.json`：总时长 16–40 秒；5–8 镜；必须有 opening / district / finale，顺序固定，opening 和 finale 各一次。
- `checks.mjs`：J1 街区 4–6 个；J2 相邻街区类型不同；J3 类别名不重复；J4 钩子大字带数字（提醒）；J5 片尾产品名 = `meta.product`、获取方式 = `meta.cta`；J6 数据必须在 `meta.facts` 里原样出现；J7 街区夹在钩子和片尾之间；J8 任何文字里的价格和时间（N 元、¥N、HH:MM、N 小时、N 分钟、N 晚）必须在 `meta.facts` 里原样出现；J9 钩子大字里的数字要么等于街区数、要么在 `meta.facts` 里；J10 夜景街区（platform / lantern）不是最后一站时提醒；J11 街区要配得上背景天际线；J12 文旅题材写到古城 / 古镇 / 老街 / 水乡，背景必须是 `oldtown`；J13 类别名像被截断的半个词提醒；J14 钩子大字照搬句式读不通（「5 个账本街」、带产品名）提醒；J15 明信片标题超过 10 字没有停顿提醒；J16 片尾既没有数据也没有获取方式提醒；J17 提示条里的日期必须在 `meta.facts` 里；J18 小引套「跟 X 一口气飞越 / 逛完」这类别家片子的招牌句式提醒。
- 行业规则照常生效（广告法极限词、促销字眼要写活动日期、文旅的等级 / 距离 / 行程说法等）。促销报错会写出触发词和位置：不是真实活动就删掉那个词，别编活动日期（编了也会被拦：日期必须在 `meta.facts` 里）。「今日精选」「今日推荐」这类栏目名不算促销字眼。
- 自查：`district` 的检查帧抽在第 3.2 拍（明信片停稳的时刻，spec 的 `checkBeat`），画面上必须看得见这一站的标题和类别名、且不混进别的站的类别名（spec 的 `mustShow`，`scripts/lib/layout-check.mjs` 判；车票只写当前站，不写「下一站」）。
- 组件层保证：明信片文字绑定在自己这一张上，寄出途中不换字；世界里的字不出现半截；片尾不写网址（集章卡卡头只写产品名）；城市背景（整块 SVG）标了 `data-probe-skip`，不参与版式检查；夜站台街区屋顶牌上的字取自分镜（类别名、标签），不写死任何语言。

## 和参考片的区别（摘要，全文见 `originality.md`）

保留的骨架：一镜到底横移、三层视差、一站一类、每站一个笑点、减速当特写、天色从白天走到夜。换掉的皮肤：配色（整套换成邮路绿 / 石墨 / 青柠，ΔE2000 ≥ 20）、左上品牌胶囊 + 右上类别胶囊 + 进度点 → 顶部车票路线图；每站一块高架广告牌 → 甩进来又寄出的明信片；描边硬投影红色大数字 → 翻牌站牌；整屏缩进浏览器 + 数据卡 → 停在终点、集章卡盖章（数据竖排 + 集章小圆牌，角色在右下角，告别语是车票口吻）；角色和载具是本项目原创；固定台词和小引句式全部重写；尖刺爆炸框 → 邮戳形拟声框；笑点桥段整套换成车站 / 邮路题材（道口下腰、邮筒贴邮票、检票打孔、大头贴三连拍、刺猬搭车、夜站台亮灯；古城是城门盖印、锦鲤跃出），不用参考片的书堆起点、倒数火箭熏黑、机械臂掸灰、双相机闪光摆拍、机器鸟结伴、霓虹故障。

## 适合 / 不适合

- 适合：内容多、类别清楚的产品——内容平台、功能多的软件、多门店或多品类、课程体系、一条游线。一个街区对应一个类别 / 功能 / 站点，一张明信片对应一条代表内容。
- 不适合：单一卖点或要讲流程的产品（用 cards）；需要真实截图演示核心动作的场合（这个风格不放产品界面）。
