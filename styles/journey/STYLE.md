# journey 风格（角色漫游）· 规格草稿

> 状态：**骨架**（`status: skeleton`）。本页是拆解要点的匿名化版本，由风格负责人补全、按实现回写数值。
> 参考了一支角色漫游类短视频（4:5，约 30 秒）。参考视频、截图、角色、品牌、网址都不进仓库；这里只有我们自己写的拆解文字。

一个吉祥物乘交通工具，从左到右一镜到底横穿一座扁平插画城市。每个街区代表一个内容类别，路边广告牌是这个类别的代表内容，天色从白天走到夜晚，最后落到产品界面和数据卡。

## 1. 基本参数

- 默认 4:5（1080×1350），也支持 9:16；30 fps；120 BPM（一拍 0.5 秒）。
- 一镜到底，没有切点，只在结尾有一次缩框。
- 每个街区正好 4 秒（8 拍），右上类别胶囊在每个街区的第 0 拍准点切换。
- 没有旁白，台词全靠气泡和拟声字。

## 2. 叙事结构

钩子 2 秒 → 4–6 个街区（每个 8 拍）→ 数字收尾约 1.3 秒 → 缩框落版约 2.7 秒。

每个街区的 8 拍：

| 拍 | 发生什么 |
|---|---|
| 0 | 路牌经过角色，类别胶囊切换 |
| 1–3 | 广告牌从头顶掠过（代表内容标题） |
| 3–6 | 本街区道具的笑点，配表情、气泡或拟声字，镜头同时减速 |
| 6–7 | 恢复巡航 |

笑点类型轮换不重复：障碍 → 帮助 → 表演 → 伙伴 → 故障。

## 3. 视觉系统

- 扁平平涂，统一深色描边：角色和道具 4px，前景楼 3px，中景楼不描边。
- 白天底色奶白、品牌强调红；每个街区一种主色（6 色轮换）；夜景深紫天、暖黄窗灯、两种霓虹。数值在 `template/src/styles/journey/tokens.json`。
- 描边大字只在钩子出现一次。参考片其余字号（广告牌 39、路牌 40、气泡 27、来源 18）都低于我们的底线，我们统一放大约 1.4 倍（广告牌 56、路牌 56、气泡 40、来源 28），因此街区上限 6、气泡 ≤10 字。
- 角色是拟物吉祥物坐交通工具，约 10 种表情，全部硬切。我们要自己画 2–3 个可选吉祥物和 3 种载具，**不用纸飞机 + 吉祥物这个组合**（和参考片太像）。

## 4. 镜头语言

- 角色固定在画面左侧约 35% 处，上下漂浮 ±16px，周期 2 秒。
- 三层视差（实测）：远景天际线约 0 px/s；云、中景楼和广告牌约 0.72 倍；前景街面 1.0 倍（巡航约 553 px/s）。
- 每个大笑点减速到巡航的 0.52–0.7 倍，减速起到特写的作用。
- 唯一的景别变化：结尾整屏在 0.3 秒内缩到 0.72，进入产品界面框（用我们自己的 mockApp/Screen 画的界面，不用真实网页截图）。

## 5. 动效语言

钩子字弹出 0.17 秒（从 0.45 倍放大）；气泡弹出 0.1 秒、停 0.65–0.9 秒；拟声字弹出 0.07 秒、停 0.3–0.45 秒；类别胶囊切换 0.13 秒。广告牌、路牌、道具没有入场动画，跟着所在层滚进来。天色从黄昏到夜线性插值约 2.2 秒；数字滚动 1.0 秒 ease-out。没有打字机，没有逐字高亮。

## 6. 元件库（12 个，计划）

`mascotRider`（角色 + 载具）、`hookTitle`、`billboard`、`districtSign`、`categoryHud`、`speechBubble`、`burst`（拟声字）、`districtProps`（道具和笑点枚举）、`groundCards`、`skyCycle`、`counterCard`、`browserOutro`。

实现建议：整片写成风格的 `Film`（见 `template/src/styles/types.ts`），分镜里一个街区一镜只是数据，世界坐标反推——先定笑点发生的时刻，再把道具放在那一刻正好到角色面前的位置，音画才对得上。现有的 `district` 镜头只是打通链路的占位。

## 7. 声音

两次 drop 都对着画面高潮（第 2 个街区的发射时刻、第 4 个街区的闪光时刻），中间有一段接近静音的 breakdown；结尾淡出。整拍留给路牌和胶囊切换，音效多落在拍后 0.1–0.4 秒的反拍上；每个拟声字配一个音效，气泡不配。

## 8. 可变与不变

- 固定：描边、UI 带、广告牌和路牌外形、视差比例、速度曲线、每街区 8 拍、天色走向、落版方式。
- 便宜模型填：钩子数字、每个街区的类别名和标题、道具和笑点（从枚举选）、收尾数据、品牌、口号、行动语。
- 最少 11 个字符串就能出一支约 22 秒的片：钩子 1 个 + 4 ×（类别名 + 标题）+ 品牌 + 口号。

## 9. 规则（都要写成校验）

- 街区 4–6 个，每个时长必须是整拍；第 0 帧必须有场景、角色和钩子字。
- 字数上限：钩子 ≤6、类别名 ≤6、标题 ≤26（放大字号后建议 ≤18）、气泡 ≤10、拟声字 ≤5；字号 ≥40 / 最小 26。
- 相邻街区道具和笑点不重复；每个拟声字配音效；落版不放网址（写产品名，获取方式照抄 `meta.cta`）。
- 广告牌不许在离场途中换字（参考片自己有一处两条标题叠字的缺陷）。
- 收尾数据必须能在 `meta.facts` 里找到来源。

## 9:16 适配

多出 570px 高：广告牌上移到原字幕带（这个风格不用全局字幕），地平线放在 y≈1560。令牌里分别有 `layout45` 和 `layout916`。

## 必须避开的参考片资产

角色造型、角色名和外文写法、品牌胶囊、网址、口号、那五个类别的整套组合、原标题、具体数字、载具上的标签。

## 适合 / 不适合

- 适合：内容多、类别清楚的产品——内容平台、功能多的软件、多门店或多品类、课程体系。一个街区对应一个类别或卖点，一块广告牌对应一条代表内容。
- 不适合：单一卖点或要讲流程的产品（用 cards）。
