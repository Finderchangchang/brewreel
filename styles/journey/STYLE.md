# journey 风格（角色漫游）

> 状态：**stable**。参考了一支角色漫游类短视频（4:5，约 30 秒）。参考视频、截图、角色、品牌、网址都不进仓库；这里只有我们自己写的拆解和实现说明，角色、城市、招牌、示例内容都是本项目原创。

一个吉祥物（小熊猫崽「橘团」）踩悬浮滑板，从左到右一镜到底横穿一座扁平插画城市。每个街区代表一个内容类别，头顶广告牌弹出这个类别的代表内容，天色从白天走到夜晚，最后整个城市缩进产品界面，落到品牌卡和数据卡。

## 1. 基本参数

- 默认 4:5（1080×1350），也支持 9:16；30 fps；120 BPM（一拍 0.5 秒）。
- 一镜到底，没有切点，只在结尾有一次缩框。
- 每个街区 8 拍（4 秒），右上类别胶囊在每个街区的第 0 拍准点切换。
- 没有旁白，台词全靠气泡和拟声字。
- 典型长度：钩子 2 秒 + 6 个街区 24 秒 + 片尾 4 秒 = 30 秒；4 个街区约 22 秒。

## 2. 叙事结构

`opening`（4 拍）→ `district` × 4–6（每个 8 拍）→ `finale`（8–10 拍：减速 + 数字卡 1.3 秒、缩框 0.3 秒、落版）。

每个街区的 8 拍（由 `district` 的 `scene` 决定地标、道具和笑点，时刻写在 `tokens.json` 的 `scenes`）：

| 拍 | 发生什么 |
|---|---|
| 0 | 类别色箭头路牌经过角色（下挂「第几站」小牌），右上类别胶囊切换、进度点 +1 |
| 0.3 | 广告牌从楼后升起，边升边弹出「类别色带 + 标题」（牌面钳在安全区里，9:16 是 x180–900） |
| 0.3–7.2 | 标题一直完整可读：牌子先停在安全区右沿，跟着视差往左滚，到左沿停住 |
| 3–6 | 本街区的笑点：道具正好到角色面前，镜头减速到 0.52–0.7 倍，角色换姿态和表情，拟声字 + 音效，随后气泡台词 |
| 3.2 | 自查检查帧抽在这一拍（spec 的 `checkBeat`）：广告牌标题和类别名必须看得见（`mustShow`） |
| 7.2 | 广告牌收起、沉回楼后，下一站的牌子紧接着升起 |
| 6–7 | 恢复巡航，下一块路牌入画 |

## 3. 视觉系统

- 扁平平涂，统一墨色 `#1F191A` 描边：角色 5px，近景楼和道具 4px，中景不描边（低饱和 + 无描边 = 天然退后）；只有天空用一道竖向渐变。
- 城市（`template/src/styles/journey/art/`）：天空 → 远景天际线 → 中景淡色塔楼 + 主题剪影 → 近景主题街区 → 街面（人行道 + 柏油路黄虚线；9:16 下方多出的地方是路缘 + 草地）。oldtown 换一套背景：远山宝塔 → 淡色白墙群 → 白墙黛瓦民居 + 垂柳 → 石板路 + 河道。每个街区一套主色（资料钴蓝、发布番茄红、工具琥珀、创意洋红、数据青、夜景绿、手机靛蓝、住家珊瑚、咖啡焦糖、集市橙红、城门朱红、石桥灰蓝、茶馆茶绿、灯会大红），类别胶囊、广告牌色带、路牌、片尾 chips 都用这个颜色，楼群和 UI 一个颜色。
- 天色自动：一个进度值管全部（白天 → 午后 → 黄昏 → 蓝调 → 夜）。最后一个街区是夜，倒数第二个黄昏，倒数第三个暖色（≥5 个街区时），其余白天；两站之间约 2.2 秒过渡；建筑自动套暖光 / 夜色，窗灯、路灯光锥、招牌仰射灯、霓虹跟着亮。
- 广告牌：顶部类别色带（白点 + 类别名 + 右侧可选标签）、白底标题（≤2 行，每行约 12 字）、可选一行出处、单根粗立柱 + 横撑、两盏仰射灯；夜里打光。霓虹街的广告牌是深底霓虹牌。
- 开场起点台：中性的圆台 + 条纹（古城是一座石墩），不带任何题材道具。
- 路牌：类别色箭头牌指向前进方向，立柱 = 街区分界，下挂「第几站」小牌。
- 字号（1080 宽，已按底线放大）：钩子大字 124（红填充 + 深描边 + 硬投影，全片唯一的描边大字）、小引 48、广告牌标题 46（最小 40，两行）、色带类别名 / 标签 28、出处 26、路牌 44、类别胶囊 34、品牌胶囊 30、气泡 40、拟声 46、数字卡 76/40、落版口号 48、行动语 40、chips 28、数据胶囊 40/26。
- 角色：原创小熊猫崽「橘团」（暖橘大圆头、环纹大尾巴、青绿围巾）踩电光蓝悬浮滑板。剧情表情 11 种全部硬切（常态 / 开心 / 兴奋 / 惊讶 / 压扁 / 松口气 / 被熏黑 / 好奇 / 摆拍 / 眩晕 / 挥手），由 `parts/rider.tsx` 翻译成美术的姿态、表情和头顶特效。**不用纸页角色 + 纸飞机这个组合**（和参考片太像）。
- 配色主题（`themes`）只管 UI 和落版：`day-city`（奶白落版底 + 品牌红）、`mint-town`（薄荷 + 墨绿，给二创示范）。城市和角色的颜色改 `tokens.json` 的 `art` 键（见 `art/README.md`）。

## 4. 镜头语言

- 角色屏幕锁定在画面左侧 35%，上下漂浮 ±16px（2 秒一周期）、左右微晃 ±8px（4 秒）；视线 = 运动方向，道具都从右边来。
- 视差：远景 0.12、中景 0.55（`camera.parallax.artFar/artMid`）、广告牌 0.42、近景 1.0。广告牌比中景还慢，是因为字号放大后要多给读的时间；广告牌下半截藏在近景楼后面，看不出层次错位。
- 相机 x(t) = ∫速度：开场怠速 65 px/s，钩子后半段起飞加速到巡航；每个街区的笑点窗口减速（`scenes.*.slow`）；片尾 1.3 秒减速到 0。**减速就是这个风格的特写。**
- 每个街区单独定巡航速度，让美术街区（2200 世界单位 × 城市缩放）正好首尾相接：4:5 缩放 0.9（一站约 1980px，巡航约 550 px/s），9:16 缩放 1.0（一站 2200px，约 610 px/s）。缩放写在 `tokens.layout.*.cityScale`。
- 世界坐标反推（`parts/plan.ts`）：路牌 = 第 0 拍到角色；广告牌 = 第 2.5 拍中心在画面 60% 处（再钳进安全区）；道具 = 第 `gagAt` 拍到角色面前；整座城市再整体错开一点，让发布街的火箭正好在笑点拍停在角色前方。音画对齐不靠碰运气。
- 唯一的景别变化：片尾整个世界 0.3 秒缩到 0.72 倍进浏览器框（地址栏只写产品名），框上半截是用各街区标题拼的内容卡片墙，下半截透出夜景，角色出框挥手。

## 7. 声音

- 整拍留给路牌（tick）和胶囊切换；拟声字都配一个音效，落在拍后（`scenes.*.sfx`，单位拍）；气泡不配音效。
- 开场：大字 pop、起飞 whoosh。片尾：计数 tick ×3、落定 ding、缩框 swish、品牌卡 pop。
- 配乐按 120 BPM 生成；两次高潮（发射、闪光）落在重拍附近。

## 8. 可变与不变

- 固定：描边、UI 带、广告牌和路牌外形、视差比例、速度曲线、每街区 8 拍、天色走向、落版方式。
- 便宜模型填：钩子数字和小引；每个街区的类别名、标题、街区类型（可选标签、出处、台词、拟声字）；片尾口号、获取方式、1–2 个数据。字段清单和字数见 `recipes.md`。
- 最少 13 个字符串出一支约 22 秒的片：钩子 1 个 + 4 ×（类别名 + 标题 + 街区类型）+ 口号（产品名默认取 `meta.product`）。

## 9. 规则（都已写成校验）

- spec：钩子大字 ≤6 字；小引 ≤10；类别名 ≤6；标题 ≤20；标签 ≤6；出处 ≤14；气泡 ≤10；拟声 ≤5；口号 ≤12；数据值 ≤6、单位 ≤5；时长范围和默认值。
- `rules.json`：总时长 16–40 秒；5–8 镜；必须有 opening / district / finale，顺序固定，opening 和 finale 各一次。
- `checks.mjs`：J1 街区 4–6 个；J2 相邻街区类型不同；J3 类别名不重复；J4 钩子大字带数字（提醒）；J5 片尾产品名 = `meta.product`、获取方式 = `meta.cta`；J6 数据必须在 `meta.facts` 里原样出现；J7 街区夹在钩子和片尾之间；J8 任何文字里的价格和时间（N 元、¥N、HH:MM、N 小时、N 分钟、N 晚）必须在 `meta.facts` 里原样出现；J9 钩子大字里的数字要么等于街区数、要么在 `meta.facts` 里；J10 夜景街区（neon / lantern）不是最后一站时提醒；J11 街区要配得上背景天际线（古城里不出现发射塔、现代城市里不冒出城门）；J12 文旅题材写到古城 / 古镇 / 老街 / 水乡，背景必须是 `oldtown`；J13 类别名像被截断的半个词（「预算提」而文案里是「预算提醒」）提醒；J14 钩子大字照搬句式读不通（「5 个账本街」、带产品名）提醒；J15 标题超过 10 字没有停顿提醒；J16 片尾既没有数据也没有获取方式提醒；J17 提示条里的日期必须在 `meta.facts` 里（有促销字眼时由公共检查报）。
- 行业规则照常生效（广告法极限词、促销字眼要写活动日期、文旅的等级 / 距离 / 行程说法等）。促销报错会写出触发词和位置：不是真实活动就删掉那个词，别编活动日期（编了也会被拦：日期必须在 `meta.facts` 里）。「今日精选」「今日推荐」这类栏目名不算促销字眼。
- 自查：`district` 的检查帧抽在第 3.2 拍（广告牌停稳的时刻，spec 的 `checkBeat`），画面上必须看得见这一站的标题和类别名、且不混进别的站的类别名（spec 的 `mustShow`，`scripts/lib/layout-check.mjs` 判）。
- 组件层保证：广告牌文字绑定在广告牌上，离场途中不换字；世界里的字不出现半截；片尾不写网址（地址栏只写产品名）；城市背景（整块 SVG）标了 `data-probe-skip`，不参与版式检查；霓虹街屋顶牌上的字取自分镜（类别名、标签），不写死任何语言。

## 适合 / 不适合

- 适合：内容多、类别清楚的产品——内容平台、功能多的软件、多门店或多品类、课程体系、一条游线。一个街区对应一个类别 / 功能 / 站点，一块广告牌对应一条代表内容。
