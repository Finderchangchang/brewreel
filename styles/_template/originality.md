## 1. 保留的骨架（类型层，可以沿用）

骨架 = 这一类视频谁都能用的做法：叙事结构、节奏、动效手法、镜头语言、版式原则、互动机制。

| 骨架 | 我们怎么用 |
|---|---|
| 叙事结构 | 例：钩子 → …… → 落版，共 __ 段 |
| 节奏 | 例：__ BPM，每段 __ 拍 |
| 动效手法 | 例：入场回弹、状态硬切 |
| 镜头语言 | 例：一镜到底 / 整页上滑转场 |
| 版式原则 | 例：一个主色 + 一个强调色 + 一个深色；关键字左对齐 |
| 互动机制 | 例：揭晓前倒数 |
