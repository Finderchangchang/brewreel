# quiz 风格的叙事模板

骨架是「猜 → 揭 → 讲 → 练 → 互动」。8 个专属镜头只能按这个顺序排，每种最多一次（`rules.json` 会拦）：

`phraseTitle → clip → quiz → meaningCard → replay → duoScene → commentCta → brandEnd`

必选 4 个：`phraseTitle`（第一镜）、`quiz`、`meaningCard`、`brandEnd`（最后一镜）。节拍 128 BPM（一拍 0.469 秒），**时长一律写 `beats`**（写 `dur` 会被吸附到整拍并提醒）。总长 30–50 秒。

字数按「汉字 1、拉丁字母和数字半个」算。下表「字段」列的数字是字数上限；**粗体**是必填。

## 先想清楚三件事（写分镜前）

1. **误解**（`guess`）：大多数人第一眼会怎么理解？它会同时出现在钩子「= 误解」（被红笔圈起来）、选项里（陷阱项）、词条卡的误解行（被波浪线划掉）。
2. **正解**（正确选项 + 词条卡的释义行）：一句话说清，最好就是产品卖点。
3. **生活里怎么用**（`duoScene` 的一问一答）：换一个场景再用一次，观众才算学会。

找不到误解就别用这个风格（改用 cards）。

## 硬规定：出题前不许剧透（校验会拦）

钩子的 `context`、`clip` 的每句台词（`text` 和 `zh`）、`quiz` 卡里的字幕签，**都不许出现正确答案、词条卡释义行的内容，也不许出现它们里的数字**。台词只露短语 / 功能名 / 菜名，让人卖关子：

- 错：「其实是小火，我们的汤熬足 4 小时」「我长按说话自动生成清单」
- 对：「这汤看起来好浓，你猜熬了多久？」「我就长按说话，松手看看」

`quiz` 卡里的字幕签默认只放 clip 最后一句里含 `key` 的那半句；要换就写 `quizLine`（≤12 字，不含答案）。答案只在 `quiz` 揭晓之后出现（meaningCard、replay、duoScene 随便说）。

## 配色（meta.theme）

可选 `sage-pine`（灰绿答题纸 + 松绿）、`rice-soy`（米纸 + 酱色）、`ash-teal`（灰纸 + 深青）。三套都用杏黄马克笔 + 朱红批改笔。不写按行业给默认：`food` 用 `rice-soy`，其余用 `sage-pine`。写别的名字会被拦。

## 口吻（phraseTitle.voice）：固定句式不写死

题号签、回放标题、印章、词条卡小签、答题卡抬头、评论提示、预填评论、便签评论、落版小标这些「每支片都有」的句子，从三套口吻里取，**不要自己抄同类视频的原话**：

| `voice` | 适合 | 题号签 / 回放 / 印章 / 评论提示 / 落版小标 |
|---|---|---|
| `exam` 考场腔 | 学习、培训 | 第 1 题 / 倒回去看 / 过关 / 把你的选项写在评论里 / 本题已掌握 |
| `chat` 闲聊腔 | 餐饮、生活 | 随口一问 / 慢放一次 / 原来如此 / 留言说说你猜的 / 又长知识了 |
| `show` 挑战腔 | 软件、功能竞猜 | 挑战题 / 回放一下 / 拿下 / 你押哪个，扣在评论区 / 这一题拿下了 |

不写 `voice` 按行业：`education` → `exam`，`food` → `chat`，`software` → `show`，其余 `exam`。想换某一句就在那一镜直接写字（`phraseTitle.tag`、`replay.title` / `sticker`、`meaningCard.label`、`commentCta.hint` / `prefill` / `comments`、`brandEnd.badge`），写了就用写的。

`quiz.question` 和 `commentCta.question` 是必填，自己写，三种写法轮换着用：

| 场合 | 考场腔 | 闲聊腔 | 挑战腔 |
|---|---|---|---|
| quiz 提问 | 「这句的意思是？」「下面哪个对？」 | 「他这句到底想说啥？」「猜猜这锅汤熬了多久？」 | 「按一下会怎样？」「松手之后会怎样？」 |
| 评论区提问 | 「你当时写的哪个？」 | 「你一开始猜的哪个？」 | 「你押的是哪个？」 |

「你猜他什么意思」「再听一遍」「评论区打个字母」「听懂了」这类同类视频用滥的原话会收到 Q14 提醒。

## 模板一：一句外语（默认，约 44–46 秒，8 镜）

适合语言学习类产品。

| 镜头 | 拍数 | 字段 | 自动 / 固定 |
|---|---|---|---|
| `phraseTitle` | 12–13 | **`phrase`**（≤6，英文约 12 个字母）、**`guess`**（≤6，直译式误解）、`voice`（`exam`）、`eyebrow`（≤10，如「口语冷知识」）、`context`（≤22，谁在什么情况下说了这句，别揭晓）、`scene` | 第 0 帧题号签 + 幽灵字 + 媒体卡在位；红笔圈疑；讲解小窗；播放键 |
| `clip` | 10 | **`lines`** 1–2 句：`speaker`（≤6）、`text`（≤20，英文原句）、`zh`（≤20，译文，可省）；`key`（≤8，最后一句里的短语，原样照抄）；`scene` | 第一句搭档说、第二句主讲人说；关键词主色 + 马克笔 |
| `quiz` | 19–20 | **`question`**（≤12，「他这句到底想说啥？」）、**`options`** 3 个（≤8，含 `guess` 原文）、**`answer`**（正确项序号，从 0 数） | 答题卡行间隔 3 拍弹出；秒表倒数 3 拍；揭晓落整拍 |
| `meaningCard` | 12–13 | **`rows`** 3–5 行：`{"kind":"word"}` 短语或其中被误解的词 → `{"kind":"neq"}` 误解 → `{"kind":"eq"}` 正解 → 可再来一组 word / eq | 主色桌面 + 词条卡；误解被波浪线划掉；第一条释义扫马克笔 |
| `replay` | 7–8 | 全可省；`title`（≤6）、`sticker`（≤4，印章字）、`zh` | 台词、关键词、正解标签沿用 clip / meaningCard；标题和印章按口吻 |
| `duoScene` | 14–16 | **`context`**（≤14，以冒号结尾）、**`ask`**（≤16，搭档问）、**`reply`**（≤10，主讲人答，含短语）、`askZh` / `replyZh`（≤18）、`key`（≤8，原样出现在 ask 或 reply 里） | 整页上滑；答完跳起、状态道具亮 |
| `commentCta` | 7 | **`question`**（≤12，如「你当时写的哪个？」）、`footnote`（≤14，自嘲一句） | 字母数和答案取自 quiz；铅笔涂陷阱项；提示、预填、便签按口吻；交卷键长成朱红方章 |
| `brandEnd` | 10–12 | **`slogan`**（两行，用 `\n` 分，≤16）、`badge`（≤10，不写按口吻）、`button`（≤8，不写用 meta.cta） | 印章落在品牌卡上；产品名取 meta.product；最后 1 秒按钮轻跳 |

合计约 94–98 拍（44–46 秒）。样例：`examples/english-im-down.json`（`ash-teal` 配色）。

## 模板二：软件功能竞猜（约 43 秒，8 镜）

「你猜这个按钮按一下能干嘛？」揭晓的正确答案就是产品卖点。口吻默认 `show`。

| 镜头 | 拍数 | 怎么写 |
|---|---|---|
| `phraseTitle` | 12 | `phrase` 写按钮 / 功能名（「双链」），`guess` 写大家怕它干的事（「复制一份」「删掉了」），`scene: "screen"`（产品界面示意）+ **`screenItems`**（界面里 2–4 行真字，每行 ≤10，如「上周用户调研」「周会纪要」；不写会被拦）。功能是「按住 / 点一下之后发生什么」的，用 `scene: "phone"`：clip 和 quiz 里只演到按住（列表是「？」），回放时才演出列表逐条出现 |
| `clip` | 10 | 两句同事对话，第二句原样包含功能名当 `key`，**只露功能名，不露效果**（「我给它加了双链」，不写「我加了双链，两篇就能互相跳」）；`scene: "office"` 或 `"phone"` |
| `quiz` | 19 | `question` 如「按一下双链会怎样？」；选项：误解 / 正确功能 / 一个干扰项 |
| `meaningCard` | 12 | word 功能名 / neq 误解 / eq 它真正做什么 / eq 带来的好处 |
| `replay` | 8 | 可全省；`sticker` 可写贴题的印章字（「找到了」「拆好了」）。有 clip 就别省这一镜（`phone` 场景的结果就在这里演出来） |
| `duoScene` | 14 | 一个急事（「开会前两分钟」），一句求助，一句用这个功能解决 |
| `commentCta` | 7 | 「你押的是哪个？」 |
| `brandEnd` | 10 | 口号两行；`meta.cta` 超过 8 字时写 `button` |

meta：`industry: "software"`，`action` 写用户在产品里做的那个动作，`disclaimer` 写「演示场景，界面为示意」。样例：`examples/software-notes-backlink.json`、`examples/software-archive.json`、`examples/software-voice-list.json`（`phone` 演示）。

## 模板三：餐饮 / 行业竞猜（约 40 秒，7 镜，省掉 replay）

「猜猜这锅汤熬了多久？」数字题最抓人，但**数字必须来自简报**。口吻默认 `chat`，配色默认 `rice-soy`。

| 镜头 | 拍数 | 怎么写 |
|---|---|---|
| `phraseTitle` | 12 | `phrase` 写名字唬人的菜 / 说法（「老火汤」），`guess` 写字面误解（「大火煮一会儿」），`scene: "street"` |
| `clip` | 10 | 客人问、店长卖关子，第二句包含 `key`，**只露菜名，不说做法和数字**（「老火两个字，你猜猜看」，不写「其实是小火熬 6 小时」）；`scene: "cafe"` |
| `quiz` | 19 | 正确项带简报里的数字（「小火熬 6 小时」），**错误选项不写阿拉伯数字**（写「大火煮一会儿」「隔夜泡一晚」这类定性说法）。题目问「几个小时 / 多少 / 几次」时，每个选项都要是数量：错误项用中文数字（「一小时 / 6 小时 / 十二小时」）；想用定性选项就把题目改成问做法（「这锅汤是怎么熬的？」） |
| `meaningCard` | 12 | word / neq 误解 / eq 做法 / eq 带数字的事实 |
| `duoScene` | 15 | 带朋友来店里，一问一答再说一次那个事实 |
| `commentCta` | 7 | 「你一开始猜的哪个？」 |
| `brandEnd` | 11 | 口号 + 店名；`meta.cta` 如「到店尝一碗」 |

meta：`industry: "food"`，`facts` 抄简报原话（`{"id":"f1","text":"招牌老火汤每锅用小火熬6小时","source":"后厨熬汤记录（商家自证）"}`），屏幕上的每个带单位的数字都要在 facts 里找得到。不写「最正宗」「第一」「现熬」「养胃」这类词（food 行业规则会拦）。样例：`examples/food-slow-soup.json`。

## 最短版（约 30 秒，5 镜）

`phraseTitle`（13）→ `quiz`（20）→ `meaningCard`（13）→ `commentCta`（7）→ `brandEnd`（12）= 65 拍 ≈ 30.5 秒（总长不能低于 30 秒）。没有 `clip` 时 `quiz` 卡里的字幕签要自己写 `quizLine`（≤12，不含答案），不写就不出字幕签；也没有回放，词条卡底部的「例」栏会退到 `duoScene` 的回答（都没有就不出「例」栏）。

## 常见错误（校验会拦，照提示改）

- `guess` 和选项差一个字 → 陷阱项对不上。原样复制。
- `answer` 从 1 数 → 选项是从 0 数的，第二个选项写 1。
- `key` 大小写和台词不一致（`No big deal` 和 `no big deal`）→ 马克笔落不下去。
- 评论区写「你第一反应选的哪个」→「第一」是广告法极限词，换成「你一开始猜的哪个」。
- 便签评论写「秒答」「秒出」→ 速度说法没有简报依据会被拦，换成「没悬念」「稳」这类。
- 错误选项写了「2 小时」这类数字 → 会被当成商家说法去找来源；改成定性说法。
- `meta.cta` 太长（>14 字）→ 按钮放不下，给 `brandEnd` 写 `button`（≤8，是 meta.cta 里的关键几个字）；`button` 和 `meta.cta` 对不上会被拦。
- clip 台词、quiz 字幕签里出现答案或答案里的数字 → 剧透，改成卖关子。
- 题目问「几个小时」，选项却是「大火煮一会儿」→ 题和选项对不上。
- 软件题材没写 `screenItems` → 界面只有灰条占位，会被拦。
- 抄了同类视频的原话（「你猜他什么意思」「再听一遍」「评论区打个字母」「听懂了」）→ Q14 提醒，换成自己的句式或删掉字段走口吻。
- `commentCta` 可以写 `comments`（1–3 条 ≤12 字的「别人的评论」，贴成便签）；不写按口吻生成两条。
