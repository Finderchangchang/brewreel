# quiz 风格（答题互动）· 九层规格

> 状态：**stable**。数值以 `template/src/styles/quiz/tokens.json` 为准。
> 骨架（猜 → 揭 → 讲 → 练 → 互动的叙事、节奏、动效手法、换场）来自一支答题互动类短视频的拆解，这是这一类视频共用的做法；
> 皮肤（配色、字号层级、元件造型、角色出场方式、固定句式、收尾方式）是 v0.2.1 重做的「批改纸」，逐条对照见 [`originality.md`](originality.md)。
> 参考视频、截图、角色、品牌名、网址、影视片段都不进仓库。

核心：**先让观众猜错一次，再告诉他为什么**。和学什么无关，任何有常见误解、能出成一道选择题的东西都能套：一句外语、一个被误会的按钮、一道名字唬人的菜。

皮肤一句话：**一张点阵答题纸，老师拿朱红笔在上面批改**。存疑的理解被红笔圈起来，答案在答题卡上揭晓，释义是一张压在桌面上的词条卡，懂了就盖章。

## 1. 基本参数

| 项 | 做法 |
|---|---|
| 画幅 | 9:16，1080×1920，只支持 9:16 |
| 时长 | 30–50 秒，5–8 镜（`rules.json` 拦） |
| 节拍 | 128 BPM，一拍 0.469 秒；时长一律写 `beats` |
| 旁白 | 没有语音合成时按固定读速点亮：旁白 6 字/秒、提问 9 字/秒、释义 8 字/秒。写了 `meta.voice` 时每镜的 `vo` 由语音合成念出，镜头时长按声音改写，主体区下沿加一条字幕条逐字跟声音点亮（写法见 `recipes.md`「有配音时」） |
| 切点 | 页面固定，靠元素弹出和四种换场；硬切只在进释义、进片段、进落版 |
| 内容占用 | 放进 y260–1340：媒体卡 840×473（x120–960），文字守 x150–930 |

## 2. 叙事结构

骨架是「猜 → 揭 → 讲 → 练 → 互动」。前 2 秒用一个大家都会犯的误解做钩子，第 17–18 秒才揭晓，中间靠选项、倒数吊住；揭晓后靠换底（词条卡压在桌面上）、回放复证和双人情景对话三次换场撑住。

| 段 | 作用 | 我们的镜头（拍数） | 画面 |
|---|---|---|---|
| 1 | 误解钩子 + 语境 | `phraseTitle`（12–13） | 第 0 帧：题号签、主色大短语、60% 幽灵字的「= 误解」、媒体卡、语境句前 4 字都在位；误解行点实 → 朱红笔把它圈起来、甩出手写问号 → 讲解小窗在卡下语境句左边「光圈打开」（当旁白的说话人标）→ 语境句逐字点亮 → 播放键 |
| 2 | 证据片段 | `clip`（10） | 版式不动，卡里开演；卡下左对齐引文块：说话人等宽小签 / 原文 / 译文，关键词变主色、杏黄马克笔慢扫 |
| 3 | 提问 → 选项 → 倒数 → 揭晓 | `quiz`（19–20） | 版式跳切；答题卡行（椭圆涂卡格 + 选项）依次弹出；卡中央秒表倒数 3-2-1；揭晓：正确项整行变主色 + 杏黄手写勾，错误项褪灰 + 朱红小叉 |
| 4 | 释义 | `meaningCard`（12–13） | 硬切到主色桌面，一张词条卡压在上面、从侧面翻正：词头 → 误解行（朱红叉 + 波浪线划掉）→ 释义 ① ② → ▸ 相关说法；卡底「例」栏放原句 |
| 5 | 回放复证 | `replay`（7–8，可省） | 回环箭头 + 回放标题；计时签往回数、画面倒放后重播；「= 正解」书签标签 + 引文块；朱红印章批改在「= 正解」标签右端、放火花（这一镜不放讲解员） |
| 6 | 迁移到生活 | `duoScene`（14–16，可省） | 两个小人一问一答，方框气泡 + 硬投影，关键词马克笔，答完跳起 |
| 7 | 评论区交卷 | `commentCta`（7，可省） | 大提问 + 答题卡（铅笔把陷阱项那格涂黑）+ 提示行 + 仿评论框打字 + 杏黄便签评论；交卷键长成朱红方章铺满全屏 |
| 8 | 结业卡落版 | `brandEnd`（10–12） | 方章边转边缩，落成品牌卡右上角的印章；朱红勾 + 小标 + 两行口号（左对齐）+ 品牌卡 + 票根按钮 + 两个小人，定格到最后 |

信息密度：段内约每 0.5 秒有一个元素在变（点亮、圈、弹出、倒数、盖章、角色）。最短版 5 镜（约 30 秒）：`phraseTitle → quiz → meaningCard → commentCta → brandEnd`。

## 3. 视觉系统

**底子**：纯色纸面 + 36px 点阵（墨色 13%）+ 左侧一条朱红页边线（x118，40%），全片常驻（`parts/paper.tsx`）。卡片一律小圆角（14–20）+ 右下实色硬投影（6–14px），不用柔光阴影。

**色板**（`tokens.json` 的 `themes`，三套）：

| 名 | 默认 `sage-pine` | 餐饮默认 `rice-soy` | `ash-teal` | 含义 |
|---|---|---|---|---|
| bg | `#CFDCCD` 灰绿纸 | `#D9CEC6` 米纸 | `#D3D6DA` 灰纸 | 底色 |
| card | `#FBFAF3` | `#FCF8F1` | `#FBFBF8` | 卡片、气泡、答题卡 |
| ink | `#1B1F1C` | `#23201C` | `#1C1F22` | 唯一的深色：字、描边、硬投影 |
| primary | `#1F5C48` 松绿 | `#7A3B1E` 酱色 | `#0F5C5C` 深青 | **关键词 / 正确项**：关键词字、正确行、释义桌面、票根按钮 |
| highlight | `#F4A81C` 杏黄 | `#F2B531` | `#F4A81C` | **马克笔**：关键词下的笔触、正确格、便签、手写勾（在主色上） |
| pen | `#CC2F45` 朱红 | 同 | 同 | **批改笔**：圈疑、叉、波浪划掉、印章、页边线 |
| wrong | `#858F88` | `#958C86` | `#899096` | 没选中 / 被划掉的灰字 |

规则：三色分工固定（主色 = 对，杏黄 = 看这里，朱红 = 老师的笔），全片不用渐变填色；主色满屏（桌面）全片只出现一次，而且上面压着纸卡。

**选配色**：`meta.theme` 写 `sage-pine` / `rice-soy` / `ash-teal`。不写按行业（`tokens.industryThemes`）：餐饮 `food` 用 `rice-soy`，其余用 `sage-pine`。三套主题和参考色板的色差见 `originality.md`。

**字号**（9:16 像素，约 1.25 倍级差：44 → 56 → 70 → 88 → 110 → 138）：

| 层级 | 用途 | 字号 |
|---|---|---|
| 特大 | 钩子短语 / 词头 / 秒表数字 / 产品名 | 138（按宽度自动缩，最小 88）/ 132 / 150 / 110 |
| 大 | 「= 误解」行、相关说法、CTA 提问、口号 | 70 / 88 / 70 / 70 |
| 中 | 提问 / 释义行 / 语境句 / 选项 | 64 / 60 / 56 / 50 |
| 正文 | 字幕、气泡 / 旁白 / 评论 / 便签、译文 | 46 / 44 / 42 / 40 |
| 标签 | 书签标签 / 小标题 / 题号签、说话人、脚注 | 34 / 30 / 28 |

字体：正文和标题用 NotoSansSC 800（不用 900），拉丁字距 -1%；**所有标签用等宽字**（题号签、说话人、计时签、答题卡字母、秒表数字，`PMono`，字距 +8%）。强调只有三种：换主色（关键词）、杏黄斜切马克笔（字高下 38%，从左往右扫出）、朱红批改笔（圈、叉、波浪线）。

**版式网格**：一律左对齐（文字 x150 起），只有秒表和印章居中。纵向：顶部合规小字（y216）→ 题号签 y284（和小字至少隔 24px）→ 标题 y344 → 媒体卡 y632（钩子位）或 y404（提问位）→ 卡下引文 / 答题卡行，主体到 y1340；y1340 以下是平台按钮区，纸面只画页脚小物（页底虚线、斜贴胶带、右沿三枚索引签、右下折角），不放信息。答题卡行高 104、间距 22、描边 4、圆角 14，涂卡格 84×58 椭圆；4 个选项时自动等比压扁放进 y1340 以内。讲解小窗直径 128，只在钩子镜出现，停在卡下语境句的左边（圆心 x≈230），语境句右移让位。

**插画**：扁平平涂，统一墨色描边，线头圆润，无渐变。两个角色在 `template/src/styles/quiz/art/`，一矮一高：主讲人约 3.6 头身，栗色侧分发 + 低马尾 + 头戴式耳机，橙色运动外套 + 松绿短裤；搭档高大宽肩，反戴棒球帽，松绿毛衣配橙色胸口横条 + 沙色工装裤。衣服用固定的角色色板（`art/colors.ts` 的 `CAST`），换主题不换衣服，描边和底色跟主题走；主题里写 `castWarm` / `castDeep` / `castLight` / `castSand` / `castGlow` 可以整套换衣服颜色。「懂了」= 耳罩亮成杏黄、发出三道声波弧（`bulb` 参数 0..1 驱动）。

## 4. 镜头语言

页面本身不推不拉不摇、没有视差，像一张固定在桌上的答题纸。真正的「镜头」只在媒体卡里：小剧场自动切全景 / 说话人近景并慢推（台词 ≥1.2 秒时），回放时倒带。

换场只有四种（`tokens.transitions`，整片渲染器 `film.tsx` 统一做）：

| 换场 | 时长 | 用在 |
|---|---|---|
| jump 版式跳切 | 1 帧，同一张卡跳到新位置，其余元素全撤，配 swish | 进 `quiz` |
| cut 硬切 | 1 帧；切到桌面时词条卡和词头已在位（不留纯色空帧） | 进 `meaningCard`、`clip`、`brandEnd` |
| dim 压暗溶解 | 3 帧 | 进 `replay` |
| pushUp 整页上滑 | 0.2 秒，easeInOutCubic | 进 `duoScene`、`commentCta` |

另有一个跨镜头的**印章擦除**：评论框的交卷键长成一枚朱红圆角方章、转着 0.1 秒铺满，下一镜只停 1 帧就 0.26 秒边转边缩，落成品牌卡右上角的印章（缓出，前两三帧就露出内容）。整屏纯色不超过 4 帧；`make.mjs` 出片后逐帧查空帧。

## 5. 动效语言

| 动作 | 时长 / 参数 | 要点 |
|---|---|---|
| 幽灵字点亮 | 拉丁每词 0.37 秒，汉字每字 0.1 秒，单字淡入 2 帧 | 钩子第 0 帧可读：短语实色、误解行 ≥60%、语境句前 4 个字已亮 |
| 逐字打出 | 旁白 6、提问 9、释义 8、评论框 7 字/秒 | 没打到的字不显示但占位 |
| 红笔圈疑 | 0.32 秒画一个不收口的手绘圈，尾巴接一个手写问号（0.2 秒） | 圈住「= 误解」 |
| 讲解小窗 | 光圈打开 0.24 秒（0 → 1.08 → 1），主色外环顺时针画一圈 | 停在卡下语境句左边当说话人标，会说话 |
| 选项弹出 | 0.27 秒，缩放 0 → 1.05 → 1，间隔 3 拍 | 音效比画面早 0.08 秒 |
| 秒表倒数 | 一拍一个，入场 0.13 秒 1.25 → 1；杏黄外圈在这一拍里走空 | 叠在卡中央 |
| 揭晓 | 状态 1 帧切换；正确项 0.2 秒放大到 1.03 回弹；勾叉 0.14 秒画出 | 揭晓落在结束前 ≥1.5 秒的整拍上 |
| 词条卡翻正 | 0.28 秒，rotateY 26° → 0（回弹） | 第 0 帧卡已经可见 |
| 波浪划掉 | 字出完 0.1 秒后开始，0.18 秒从左往右露出 | 朱红锯齿，不是直线 |
| 马克笔 | 1.5 秒慢扫（释义第一条 0.6 秒） | 斜切笔触 |
| 盖章 | 0.14 秒，1.35 → 1，旋转 -7° | 配低频「咚」 |
| 火花 | 0.45 秒，上升 110px，5 颗四角星 | 杏黄和朱红两色 |
| 铅笔涂卡 | 0.45 秒来回排线涂满椭圆 | 评论区的陷阱项 |
| 角色放大进场 | 0.2 秒，0.2 → 1，以脚底为锚点，两人相隔 0.1 秒 | |
| 气泡 | 0.13 秒，0.6 → 1，以尾巴尖为锚点；回答先幽灵后实 | |
| 结尾 | 整版在前 0.5 秒内入场后定格；最后 1 秒票根按钮轻跳、放火花，不淡出 | CTA 一直留到最后一帧 |

整体：入场都带回弹，状态切换 1 帧硬切，换场都在 0.2 秒以内（印章擦除除外）。倒数和揭晓严格落拍，其余跟文字节奏走。

## 6. 元件库

镜头（`template/src/styles/quiz/shots/`，字段和字数上限见各自的 `.spec.json`，便宜模型的填法见 `recipes.md`）：

| 镜头 | 必填字段 | 画面 |
|---|---|---|
| `phraseTitle`（第一镜） | `phrase` ≤6、`guess` ≤6 | 题号签 + 大短语 + 被圈起来的「= 误解」+ 媒体卡 + 讲解小窗 + 语境句 + 播放键；`voice` 选全片口吻 |
| `clip` | `lines` 1–2 句（`text` ≤20） | 沿用钩子标题，卡里开演，卡下引文块 |
| `quiz` | `question` ≤12、`options` 2–4 个 ≤8、`answer` | 提问、答题卡行、秒表倒数、批改式揭晓 |
| `meaningCard` | `rows` 3–5 行（word / neq / eq，≤8） | 主色桌面 + 词条卡 |
| `replay` | 全可省 | 回放标题 + 计时签倒带 + 印章 |
| `duoScene` | `context` ≤14、`ask` ≤16、`reply` ≤10 | 两个小人一问一答 |
| `commentCta` | `question` ≤12 | 答题卡 + 提示 + 仿评论框 + 便签评论 + 印章擦除 |
| `brandEnd`（最后一镜） | `slogan` 两行 ≤16 | 结业卡：小标、口号、品牌卡 + 印章、票根按钮、两个小人 |

字数按「汉字 1、拉丁字母半个」算，所以 `phrase` ≤6 约等于 12 个英文字母。

元件（`parts/`）：`kit.tsx` 幽灵字 / 打字（中文按词不断行）、马克笔、批改笔（`PenCircle` 圈疑、`Scribble` 波浪划掉、`Mark` 手写勾叉）、`Seal` 印章、`Sparks` 火花、`TagRow` 题号签、`Label` 书签标签、`cardStyle` 硬投影卡片、`useVoice` 口吻；`media.tsx` 媒体卡、播放键、`TimecodeChip` 回放计时签、`CaptionTag` 卡内字幕签、`Countdown` 秒表、`SubStack` 引文块、`HookHeader` 钩子标题头；`cast.tsx` 角色、头像、`Presenter` 讲解小窗、小剧场的接口层（镜头只从这里拿角色）；`paper.tsx` 纸面背景。

媒体卡里放什么（`scene` / `media`）：
- `office` / `cafe` / `street` / `home` / `classroom`：我们的两个角色在场景里把那句话演出来（默认 `office`）。
- `screen`：一块产品界面示意，界面里的 2–4 行字写 `screenItems`（真字，34px）；软件题材必须写（校验会拦）。
- `phone`：手机演示——手指按住说话键 → 波形跳 → 松手 → 列表逐条出现 `screenItems`。钩子里是待机、clip 和 quiz 里只演到按住（列表是「？」占位），`replay` 才演出结果。
- `media`：用户自己有版权的截图或视频（登记在 `meta.assets`）。

## 7. 声音

- 配乐轻快（约 128 BPM）：开头只有稀疏铺底，揭晓瞬间鼓组进入，释义段后段停鼓留白，结尾和弦。
- 配音（可选）：旁白按镜头起点 + 0.15 秒开口；配乐在人声处压低 10 dB（120 ms 压下、300 ms 回来），没人声的段落不变；音效照常。
- 音效由各镜头的 `sfx()` 按同一张时间表给出：

| 镜头 | 音效 | 对应画面 |
|---|---|---|
| phraseTitle | tick / swish / pop / tap | 误解行 / 红笔圈 / 讲解小窗 / 播放键 |
| clip | ding | 关键词亮起 |
| quiz | swish / pop×选项数 / tick×3 + whoosh / ding + thud | 跳切 / 选项 / 倒数 / 揭晓 |
| meaningCard | thud + swish / pop / swish | 切桌面翻卡 / 每一行 / 波浪划掉 |
| replay | swish / whoosh / thud + bell | 溶解 / 倒带 / 盖章 |
| duoScene | swish / pop×2 / pu + bell | 上滑 / 两个气泡 / 跳起 |
| commentCta | swish / pop / tick×4 / whoosh | 上滑 / 涂卡格 / 涂卡和打字 / 印章擦除 |
| brandEnd | whoosh / pop / swish / thud / pu / bell | 缩章 / 品牌卡 / 产品名 / 印章落定 / 小人 / 锁定 |

## 8. 可变与不变

**固定（便宜模型不碰）**：色板和颜色分工、纸面、幽灵字机制和读速、版式网格、动效参数、四种换场、段落顺序、角色造型、音效映射。

**便宜模型要填的**（逐镜字段和字数见 `recipes.md`）：

| 字段 | 在哪 | 说明 |
|---|---|---|
| `product` / `cta` / `action` / `industry` / `theme` | meta | 产品名（品牌卡大字）、行动号召（票根按钮，≤14 字，更长就给 `brandEnd.button` 写关键几个字）、配色（可省） |
| `phrase` + `guess`（+ `voice`） | phraseTitle | 被误解的说法 + 大多数人的第一反应（陷阱项）；口吻可省（按行业） |
| `context`、`scene`、`screenItems` | phraseTitle | 语境一句（不揭晓）；媒体卡里演什么；界面示意里的字 |
| `lines` + `key` | clip | 1–2 句台词，最后一句原样包含 `key`；**只露短语 / 功能名 / 菜名，不许说出答案或效果** |
| `question` + `options` + `answer` | quiz | 提问、2–4 个选项（含 `guess` 原文）、正确项序号 |
| `rows` | meaningCard | word / neq（误解）/ eq（正解），3–5 行 |
| `context` + `ask` + `reply` + `key` | duoScene | 生活化一问一答 |
| `question` | commentCta | 问观众当时选了哪个 |
| `slogan`（+ `badge`） | brandEnd | 两行口号 |

**固定句式走口吻**（`tokens.voices`，`phraseTitle.voice` 选，不写按行业：教育 `exam`、餐饮 `chat`、软件 `show`）：

| 位置 | `exam` 考场腔 | `chat` 闲聊腔 | `show` 挑战腔 |
|---|---|---|---|
| 题号签 | 第 1 题 | 随口一问 | 挑战题 |
| 回放标题 | 倒回去看 | 慢放一次 | 回放一下 |
| 印章 | 过关 | 原来如此 | 拿下 |
| 词条卡小签 / 例栏 | 词条 / 例 | 说法 / 原话 | 功能卡 / 实录 |
| 答题卡抬头 | 答题卡 | 你的答案 | 押一个 |
| 评论提示 | 把你的选项写在评论里 | 留言说说你猜的 | 你押哪个，扣在评论区 |
| 预填评论 | A，交卷 | 我猜的是 A | 我押 A |
| 便签评论 | B，稳 / 我也写了 A | B！/ 我也以为是 A | B，没悬念 / 押 A 的举手 |
| 落版小标 | 本题已掌握 | 又长知识了 | 这一题拿下了 |

每一项都能在对应镜头里直接写字覆盖（`phraseTitle.tag`、`replay.title` / `sticker`、`meaningCard.label`、`commentCta.hint` / `prefill` / `comments`、`brandEnd.badge`）。英文片（`meta.lang: "en"`）取每套的英文版。

**自动推导**：片段沿用钩子的标题和场景；提问卡的字幕签 = 片段最后一句里含 `key` 的那半句（或 `quiz.quizLine`，≤12 字，不含答案）；`screenItems` 写一次全片沿用；回放的台词、关键词、正解标签沿用 clip 和 meaningCard；评论区的字母数和答案取自 quiz；落版产品名取 `meta.product`、按钮取 `meta.cta`。

## 9. 规则（都写成了校验）

声明式（`styles/quiz/rules.json`）：总长 30–50 秒；5–8 镜；必须有 `phraseTitle`、`quiz`、`meaningCard`、`brandEnd`；每种镜头最多 1 次；顺序固定 `phraseTitle → clip → quiz → meaningCard → replay → duoScene → commentCta → brandEnd`；第一镜 `phraseTitle`、最后一镜 `brandEnd`（`style.json`）。

字段级（各镜头 `.spec.json`）：必填、字数上限、选项和释义行的条数、`scene` / `voice` 枚举、时长范围。

跨字段（`styles/quiz/checks.mjs`，报错都带改法）：
- Q1 选项 2–4 个、不重复；`answer` 是合法序号。
- Q2 钩子的 `guess` 必须原样是一个选项（陷阱项），且不是正确答案。
- Q3 错误选项不写阿拉伯数字；具体数字只给正确项，并且要出自 `meta.facts`。
- Q4 `clip` / `duoScene` / `replay` 的 `key` 必须是所在台词的子串（大小写一致）。
- Q5 片段的 `key` 要和钩子短语对得上（提醒）。
- Q6 释义卡第一行是 word、恰好 1 行 ≠、至少 1 行 =；≠ 行和钩子误解、第一个词和钩子短语要对得上（提醒）。
- Q7 评论区的 `letters` / `answer` 写了就必须和 quiz 一致；`commentCta` 后面紧跟 `brandEnd`（提醒，印章擦除要接上）。
- Q8 落版要有产品名；必须有行动引导（`meta.cta` 或 `brandEnd.button`），写了 `button` 要和 `meta.cta` 对得上；按钮文案 ≤14 字。
- Q9 提问到揭晓 6–8 秒（quiz 写 17–21 拍，提醒）。
- Q10 出题前不剧透：钩子语境句、clip 台词（`text` 和 `zh`）、quiz 卡里的字幕签，都不许含正确答案、释义卡 = 行及其中的数字。
- Q11 数量题：每个选项都要是数量；错误项用中文数字，正确项的阿拉伯数字出自 `meta.facts`。
- Q12 `scene` 是 `screen` / `phone` 就要写 `screenItems`；`industry: "software"` 必须写。
- Q13 有 `clip` 没 `replay` 提醒（少了回放复证这一拍）。
- Q14 固定套话提醒：提问、回放标题、印章、评论提示、预填、落版小标里写了同类视频用滥的原话（「你猜他什么意思」「再听一遍」「评论区打个字母」「听懂了」「第一反应选的」），提醒换成自己的句式或删掉字段走口吻默认句。

行业合规照常生效（`industries/<行业>/rules.json`）：教育类不承诺提分；餐饮类不写极限词和功效，「熬了几小时」这类数字要有 `meta.facts`；速度说法（「秒答」「秒出」）没有简报依据会被拦。评论区提问别写「第一反应」（「第一」是广告法极限词）。

## 证据片段的替代方案（不用影视片段）

1. **插画小剧场**（默认）：我们的角色在媒体卡里演出那句话被说出来的瞬间，不需要外部素材。
2. **产品界面示意**（`scene: "screen"`）或截图：放进小圆角卡，叠字幕签和印章，避开「放大录屏」。
3. **用户自备视频**：版权由用户声明，登记在 `meta.assets`。

## 必须避开

参考片的产品名、网址、logo、顶部品牌小标、网址落版、那对吉祥物的造型和状态道具、影视片段及其片名和角色名，以及它的招牌细节和固定句式（逐条替换记录在 `originality.md`）。我们的落版只放产品名和行动引导，不放网址。

## 适合 / 不适合

- 适合：有一个常见误解、能出成一道选择题的产品——外语短语、被误会的功能（「归档 = 删掉了？」「双链 = 复制一份？」）、名字唬人的菜（「老火汤 = 大火煮？」）、反常识的知识点。
- 不适合：找不到可以出题的误解、只想罗列卖点或讲价格的（用 `cards`）；想展示一个完整世界或多个类别的（用 `journey`）。
