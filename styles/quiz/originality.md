# quiz 风格（答题互动）· 原创性记录

> 调配方流程第 3 步「再设计」的交付物（v0.2.1）。本文件公开：不写参考片的品牌名、角色名、网址、口号原文、影视片名，只用抽象描述。
> 招牌清单原件和参考 `tokens.json` 放在仓库外，只在命令行里引用。
> 评审标准：**同一类型，但熟悉参考片的人一眼看得出不是同一家**。

## 1. 保留的骨架（类型层，可以沿用）

| 骨架 | 我们怎么用 |
|---|---|
| 叙事结构 | 猜 → 揭 → 讲 → 练 → 互动：误解钩子 → 证据片段 → 提问 / 选项 / 倒数 / 揭晓 → 释义 → 复证 → 生活情景 → 评论区互动 → 落版，8 个镜头、顺序固定 |
| 节奏 | 128 BPM，时长写拍数；提问到揭晓 6–8 秒；倒数 3 拍、揭晓落整拍；揭晓瞬间进鼓 |
| 动效手法 | 第 0 帧幽灵字排好、逐字点亮；入场带回弹、状态 1 帧硬切；选项依次弹出；关键词马克笔慢扫；换场 ≤0.2 秒 |
| 镜头语言 | 固定机位的「页面」，镜头感只在媒体卡里（小剧场切景、倒带）；四种换场：版式跳切 / 硬切 / 压暗溶解 / 整页上滑；一个从按钮长出来、在下一镜收回的跨镜头擦除 |
| 版式原则 | 一个深色 + 一个饱和主色 + 强调色，无渐变；问答左对齐；媒体卡是 16:9 证据位；换底色全片只一次 |
| 互动机制 | 陷阱项 = 钩子里的误解；倒数后揭晓；评论区让观众报自己选的字母 |

## 2. 重做的皮肤（我们自己的）

### 2.1 配色

| 用途 | 参考片的做法（抽象描述） | 我们的做法 | 色值 |
|---|---|---|---|
| 背景 | 纯色暖奶油底，无纹理 | 灰绿「答题纸」底 + 36px 点阵 + 左侧朱红页边线；餐饮是米纸、另一套是灰纸 | `#CFDCCD` / `#D9CEC6` / `#D3D6DA` |
| 主色 | 饱和钴蓝：关键词、满屏释义卡、发送键 | 深色主色：松绿 / 酱色 / 深青，表示「关键词 / 对」 | `#1F5C48` / `#7A3B1E` / `#0F5C5C` |
| 强调色 | 荧光黄绿：对、问号块、倒数、贴纸、按钮 | 杏黄马克笔（看这里）+ 朱红批改笔（老师的笔迹）两支笔分工 | `#F4A81C`（`#F2B531`）/ `#CC2F45` |
| 深色 / 描边 | 藏青墨色 | 近黑的绿黑 / 暖黑 / 冷黑，都不带蓝 | `#1B1F1C` / `#23201C` / `#1C1F22` |

| 阴影 | 柔光大阴影 | 右下实色硬投影（墨色，品牌卡用主色） | — |

v0.2.0 里还原样留着参考片的几个中性色（错项灰、叉的暖灰、角色影、答错卡底），这次全部换掉。

### 2.2 字体处理

- 标题和正文从 900 降到 800，拉丁字距从 -2.5% 放到 -1%；字号层级改成约 1.25 倍的级差（138 / 110 / 88 / 70 / 56 / 44），大字比参考收一档、中间层拉开。
- 所有标签改用等宽字（题号签、说话人、计时签、答题卡字母、秒表数字），参考片只在顶部品牌小标用等宽。
- 强调手法：马克笔从圆角平条改成斜切笔触；否定从「降透明度 + 直线删除线」改成「灰字 + 朱红锯齿波浪线」；问号从色块改成手写红笔问号。
- 全片左对齐（参考片的字幕、译文、结尾大字居中），卡下字幕改成带主色竖线的引文块。

### 2.3 角色

- 出场方式：从「卡片上沿探头的半身小人」改成钩子镜里卡下旁白左边的圆形讲解小窗（光圈打开 + 主色外环 + 朱红在线点），当旁白的「说话人」标，会说话。v0.2.1 起不再贴媒体卡右沿；片段、回放两镜不放讲解员，由卡里的两个角色自己演。
- 造型（`art/`，见 `template/src/styles/quiz/art/README.md`）：参考是一对等高、约 4.5 头身的瘦长角色；我们是一矮一高的反差组合。
  - 主讲人：约 3.6 头身、大头；栗色侧分发 + 低马尾 + 头戴式耳机；橙色运动外套、松绿短裤、条纹袜、厚底鞋。
  - 搭档：高大宽肩；反戴棒球帽（橙色帽檐）、深棕肤色带雀斑；松绿毛衣配橙色胸口横条、沙色工装裤卷边、橙色高帮鞋。
- 人设配色：衣服、道具、小剧场家具用固定的角色色板（`art/colors.ts` 的 `CAST`：橙 / 松绿 / 沙 / 杏黄），换主题不换衣服；描边、底色、卡片跟主题走。和参考人设色的色差：上衣 48.2、裤 / 毛衣 40.7、工装裤 75.0、发色 27.3。
- 「懂了」：耳机耳罩亮成杏黄、向外发三道声波弧 + 四角星火花。头顶没有小芽、不开花、不冒心。

### 2.5 固定文案句式

固定句式不再写死在组件里，改成 `tokens.voices` 的三套口吻（`phraseTitle.voice` 选，不写按行业），每一句都能在对应镜头里直接写字覆盖；中英两版。

| 位置 | `exam` 考场腔 | `chat` 闲聊腔 | `show` 挑战腔 |
|---|---|---|---|
| 题号签 | 第 1 题 | 随口一问 | 挑战题 |
| 回放标题 | 倒回去看 | 慢放一次 | 回放一下 |
| 印章 | 过关 | 原来如此 | 拿下 |
| 评论提示 | 把你的选项写在评论里 | 留言说说你猜的 | 你押哪个，扣在评论区 |
| 预填评论 | A，交卷 | 我猜的是 A | 我押 A |
| 便签评论 | B，稳 / 我也写了 A | B！/ 我也以为是 A | B，没悬念 / 押 A 的举手 |
| 落版小标 | 本题已掌握 | 又长知识了 | 这一题拿下了 |

校验不要求任何固定原句；反过来，Q14 会提醒分镜里抄了同类视频的原话。

### 2.6 收尾方式

结业卡：朱红手写勾 + 小标 → 左对齐两行口号 → 品牌卡（logo + 产品名，主色硬投影，右上角压着由印章擦除收回来的方章）→ 票根形按钮（主色底、两端半圆缺口、虚线撕口 + 杏黄箭头）→ 两个角色放火花；定格到最后一帧，按钮轻跳，不淡出、不出网址、不单独出 logo 页。
