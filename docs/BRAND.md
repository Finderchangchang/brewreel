# 品牌档案

每个客户一份品牌档案。片子要带律所片头、角标、律师姓名条和片尾时，讲稿引用这一份。不写品牌的片子，画面和以前一样。

档案里的名字、颜色和 logo 都由客户提供。仓库和安装包里不放真实律所、真实律师，也不放 logo 原件。

## 建档

数据目录和角色档案相同。默认是当前工作目录上一级的 `brewreel-studio-data`，也可以用环境变量 `LESSON_DATA_DIR` 或参数 `--data-dir` 改。档案不能放进安装文件夹。

```
node scripts/lesson/brand.mjs create --client <客户id> --firm <律所全称> --column <栏目名> --logo <logo.svg 或 logo.png> --primary <#RRGGBB> [--english <英文名>] [--secondary <#RRGGBB>] [--lawyer <姓名> --title <职称> --department <部门>] [--qr <二维码.png>] [--tip <片尾提示语>]
```

客户 id 只用小写字母、数字和短横线。logo 和二维码在建档时复制进档案目录，并记下 sha256。提示语不写时，用「扫码咨询 · 下期见」。

多位律师可以重复写 `--lawyer`、`--title`、`--department`，也可以用 `--lawyers lawyers.json`。名单是数组，每项有 `name`、`title`、`department`。

查看某一版：

```
node scripts/lesson/brand.mjs show <客户id>
node scripts/lesson/brand.mjs show <客户id@版本>
```

要改全称、栏目、颜色、logo、律师或提示语，用 `update`，不要覆盖档案。改了任何一项，版本号加 1。

## 讲稿怎么引用

`lesson.meta.brand` 写成 `客户id` 或 `客户id@版本`。不写版本时，用当时的最新版，交付清单和 lock.json 记下实际版本和 logo 的 sha256。

`lesson.meta.episode` 是期数，可以不写。`lesson.meta.lawyer` 是律师姓名，或从 1 开始的序号，也可以不写。不写律师、档案里又有人时，姓名条用第一位。

旧讲稿里的 `meta.brand` 如果还是对象，只保留原来的校验，不启用这套包装。

## 画面上会出现在哪里

有品牌时：

- 横版封面换成片头：主色铺满，logo、律所全称、英文名、栏目和期数、本期标题。底部只有一处「AI 辅助生成」。审核律师只从审稿记录里取。测试审稿不写律师名，写「内部测试 · 未经律师审核」。没有审稿记录时，只留「AI 辅助生成」。
- 正片左上角是小 logo 和栏目名。章节行和标题一起下移，给角标让位。
- 讲解员第一次出现在内容页时，右下角圆窗上方出姓名条，停 4 秒，之后不再出现。
- 主色替换这一集主题的强调色，辅色替换点缀色。对比度不到 4.5:1 就停下来，并给出一个建议色，不会偷偷改色。
- 最后一页回顾的右侧是律所块：logo、全称、二维码或占位、提示语，底部是免责声明。法律领域的默认声明是「本视频为一般性法律知识介绍，不构成针对具体案件的法律意见。」整片没有回顾页时，末尾自动加 4 秒无旁白的品牌尾页，配乐跟着延长。
- 竖版切片和封面图加上 logo 和栏目名，放在原来的安全区里，不改讲解员和标题的既定位置。竖版姓名条在讲解员上方。

## 版本

品牌一旦用在成片里，用到的版本就固定下来。之后改档案，版本号加 1，旧版本和当时的 logo 留在档案目录里。已经交出去的片子不变。

lock.json 里记 `客户id@版本` 和 logo 的 sha256。这两项变了，算引擎以外的输入变了：变过的页面会重渲，并提示一句。这不是引擎指纹不符，不会整片拒绝。

## 事先说清楚的限制

- 不改 AIGC 隐式标识。隐式标识仍写在成片元数据里。画面上的 AI 字样只留片头这一处，不和原来的片头大标并存。
- 不改审稿、授权能不能出片的判定。审核律师这个名字只是读审稿记录，测试审稿不会被写成审核律师。
- 主色不过对比度检查时，出片直接失败。建议色只是提示，要自己改档案再出。
- 二维码可以先不给，片尾用虚线框占位。
- 英文名可以不写。不写期数时，片头只显示栏目名。
