# 讲解课版式规则

## 画布与安全区

- 成片画布为 1920 × 1080。版心为 x=120–1480、y=150–930；主体元素组在版心内垂直居中。正文与版式内容左边缘通常从 x=136px 起排版。x≤1480 的内容区不能被讲解员或便签气泡挡住。
- 卡通讲解员不加框，站在右下角：脚底 y=860，右边距 80，默认高 380（宽按 850:1200），截图页和代码页高 300。
- 真人讲解员是圆形小窗：直径 280，right 80 / bottom 108。截图页和代码页直径 220。描边 1px，阴影用各风格 token。开场钩子和章节页在稿子标了 `full` 时可以放大成圆角矩形并排大窗或横拍全屏，缩回圆形用 600ms。
- 底部字幕条在 y=864–972、x=528–1392。卡通脚底贴着这条带子的上沿，圆窗在它右侧，两者都不进入字幕带。页脚进度条仍使用最底部 8px。
- 主体宽度按版式控制在 x=120–1440px。封面右侧图形可以进入空白侧栏，但不进入讲解员和气泡实际占用的区域。便签气泡在人物或圆窗的左上方，左缘不小于 1480。

## 字号与密度

- 标题 64–96px，正文不小于 44px，引用原文不小于 52px，代码不小于 34px；出处等辅助文字不小于 28px。
- 每页必须有一个占版心面积 40% 以上的主角元素组：封面图形、步骤/流程卡、引文卡、对比栏、问题块、回顾清单、截图或代码面板。使用 `contentBox(layout, page)` 对 gallery 主体占位面积做纯函数回归校验。
- 主体按条数自适应字号、卡片高度和间距；条数少时放大并填充更多版心。不得让 quote、steps、recap、code 或 compare 只占左上区域。
- 每项文字先精简再拆页；避免只留下两行小字或让下半屏没有主体内容。
- 每个版式规格文件 `template/src/lesson/layouts/*.spec.json` 描述字段、类型和字数上限；校验失败时提示应修改的字段。

## Reveal 与手绘强调

- 元素跟随 narration 的 `reveal` 出现，入场位移与透明度变化时长约 0.35 秒。
- 每个版式 spec 的 `revealTargets` 按序说明 reveal 0、1、2……点亮的主体目标；标题不属于 reveal 目标，页面开始时可见。reveal k 累积显示 0…k。cover 与 chapter 没有主体 reveal 目标；steps、recap、flow 按条目，quote 按原文/出处，compare 按左栏/右栏，question 按题目与全部选项/揭晓，screenshot 按截图/标注，code 按代码行。
- 未被旁白 reveal 覆盖的目标中，index 0 页面开始时可见，其余在页尾前 0.5 秒补齐；整页没有 reveal 时，目标在页面开始后 1 秒内依次出现。
- 标题允许轻微打字机/淡入变化；第一页封面第 0 帧就必须可见，不能依赖 400ms 语音前导后才出现。
- 重点圈线和下划线使用组件内自行绘制的 SVG 路径动画，不依赖外部图片素材。
- screenshot 标注的 x、y、width、height 都使用 0–1 相对坐标；标注按索引 reveal。
- code 每行逐步出现，可用从 1 开始的 `highlightLines` 标记讲解重点；最多 14 行。

## 主题

- `template/src/lesson/theme.ts` 中 `light` 与 `dark` 令牌必须保持同一结构，默认使用 `light`。
- 卡片、文字、强调色、底色、细线和字幕颜色都从主题令牌读取，避免组件写死浅色画布。

## 竖版

竖版不是裁横版。同一份讲稿和时间轴另渲 `LessonVertical`，画布 1080×1920。十种版式都落在同一内容框里：单列，对比改成上下两块，代码和截图用内容框的全宽。配色、字体和字幕样式沿用四套风格。字幕条在 y=1380–1520、x=180–900。单行不超过 14 个汉字宽，只在标点或词边界断开；拆不开的英文命令单独占一行，可以放到 18 个汉字宽并缩小字号。普通行字号不小于 56px。句中逗号、句号、顿号显示成空格。

内容在 x=180–900、y=260–1340。稳态内容框从安全区顶（样片水印之下）排到讲解员上方，宽度拉满，面积至少占安全区 45%。正文不小于 48px，标题不小于 72px。片头标识和钩子只在出现的那几秒占上方：标识在安全区右上角，钩子在它下面，字号不小于 80px。钩子和当前页已经画出的标题、章节名或封面标题相同，或者一方包含另一方时，不再另画钩子，把这个标题放大到不小于 80px，并在开头 1.5 秒做一次轻微的下移收回。卡通平时高 300，右缘对齐 x=900，脚底对齐 y=1340，脸朝左。钩子出现的前 1.5 秒高 420、水平居中、站在钩子下方，再用 0.4 秒收到右下角。截图、代码、对比页高 220，换页尺寸用 0.3 秒过渡。真人圆窗同样摆：开头直径 360，平时 240，这三页 200。字幕在内容下方水平居中，不和人物重叠；放不下时字幕留在原地，人物缩到 220。便签贴在人物左缘外侧、与头顶齐平，不出安全区；左侧不够 220px 时气泡变窄，不盖住正文。人物和内容的包围盒不重叠。底部和右侧按钮区不放内容。几何在 `scripts/lesson/vertical-layout.mjs`，横版 `STAGE` 不变。

## 输入约定

版式专属字段保持在 lesson JSON 顶层，示例集中于 `examples/lesson/layouts-gallery.json`。时间轴每页的 `fields` 保留该页除 `narration` 外的全部原稿字段，含校验时注入的 `imageData`；`lang` 通过 Lesson props 传给版式。`items` 始终只保存原稿条目，不打包语言或其他版式字段。
