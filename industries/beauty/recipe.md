# 美业（beauty）推荐结构

## 1. 适用范围
美发、美甲、美睫、皮肤清洁护理（生活美容）。**不含医美**；brief 提到医美、纹绣、半永久项目一律拒绝。

## 2. 推荐结构

### A. 变身对比（仅 hair/nail/lash，需有授权的前后照片），25 秒
| 镜头 | 秒 | 目的 | 字幕示例 |
|---|---|---|---|
| hook | 2 | 用情景交代顾客诉求 | 她只说了一句\n别剪太短 |
| chat | 3 | 还原沟通，disclaimer 写"情景演示" | 想要好打理的短发 |
| steps | 5 | 展示过程，证明是手艺而非后期 | 洗护 → 剪裁 → 吹造型 |
| beforeAfter | 5 | 真实前后对比 | 顾客授权实拍 未修图 |
| photoShot(tour) | 4 | 同类作品快切 | 本店同款作品 |
| priceCard(menu) | 3 | 价格和加价条件 | 女士剪吹 88元/次 |
| storeCard(card) | 3 | 门店信息和生活美容声明 | 玉林商圈 · 预约制 |

### B. 报价拆解（没有照片也能做），20 秒
hook 2 → chat 3 → priceCard(menu，"起"价要同屏列出加价项) 6 → quickList(含什么/不含什么) 4 → features(卫生与服务承诺) 3 → storeCard 2

### C. 避坑问答（信任型，skincare 也适用），22 秒
hook 2 → quickList(3 个该问清的问题) 6 → compare(subject=habit) 5 → credCard(person) 4 → features(卫生与用料) 3 → endCard 2

变体"上新快切"（≥5 张本店作品时），16 秒：hook → photoShot(tour，每张约1秒) → factSheet(swatch) → priceCard(menu) → endCard

## 3. 钩子示例
她只说了一句\n别剪太短｜长发加价吗？\n价目表写清楚｜做睫毛前\n先问这3句｜秋冬猫眼\n选哪款？｜团购到店\n还要加钱吗？｜一客一消毒\n拍给你看｜同一位顾客\n做完是这样｜第一次做美甲\n先看这条｜换个发色\n先挑色卡｜卸甲要不要钱？\n一次说清

## 4. 镜头用法
- `beforeAfter` 只有 hair/nail/lash 且已获顾客书面授权才能用；`skincare` 品类不能用。
- 缺 `consent:true` 或 `retouched` 不是明确的 `false`，一律拦截。
- "起"价（`from:true`）必须同屏列出加价项（card 布局用 `fromNote`，menu 布局用 `addOns`）。
- "医生""专家""皮肤科"这类医疗背书一律拦截；画面不出现白大褂、针管、十字。

## 5. 视觉风格
美发：奶油白底，焦糖棕或墨黑。美甲：奶白或裸粉底加一个跳色。美睫：黑白灰，细玫瑰金线条。皮肤清洁护理：米白底，鼠尾草绿。不用医疗蓝和冷白光；作品快切每张 0.6–1.2 秒，价目表停留 ≥3 秒。

## 6. 必备提示语
`storeCard`/`endCard` 默认带「生活美容 · 不提供医疗美容服务」；`beforeAfter` 固定角标「顾客授权实拍 · 未修图」；作品旁建议注明"效果因发质/甲面等个人条件而异"；有门市价时注明"近7日成交价"；`swatch` 固定加"屏幕有色差，以到店色板为准"。

## 7. 最容易犯的 5 个错
1. 前后对比没有顾客书面授权就用——`beforeAfter` 会拦，换成 `steps` 展示过程。
2. "美白""祛斑""防脱生发"这类功效词——生活美容不能宣称，染发/烫发这类服务名称本身可以保留。
3. "永久""无副作用""100%满意"——保证类用语一律拦截。
4. "黄脸婆""显老""没人要"——制造容貌焦虑一律拦截。
5. "起"价没写清加价项——menu 布局要有 `addOns`，card 布局要有 `fromNote`。

## 核心动作和素材（校验会拦）
- 美业是实物/门店行业：核心动作用 **photoShot（商家实拍或插画场景）** 演示，过程用 `steps`。**不要用 `mockApp` 编点单页、结算页、预订页**，校验直接拦；商家真有自己小程序/店铺页的截图，用 `phone` 放截图。
- 用到的每张图先在 `meta.assets` 登记来源（merchant / illustration / screenshot）；只有 merchant 的能标「实拍」。
- 商家没照片：用插画兜底（`source: "drawn"`），会有「正式发布前补实拍」的提醒，不会拦，也不会再报「前 3 秒没有实拍」。
- `compare` 两栏写了 `level` 时，`tone: "good"` 那栏在 `meterLabel` 这把尺子上必须更优：「保温时长」越高越好，「降温速度」「麻烦程度」越高越差。
- `beforeAfter` 的前后两张必须是素材清单里同一个 `pair` 的 `customer-before` / `customer-after`，不能是同一个文件或内容相同的两张。
